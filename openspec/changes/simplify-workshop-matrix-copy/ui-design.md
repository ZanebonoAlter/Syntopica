# UI 设计（minor）
沿用现有时间视窗、网格、右轨和详情工作面，不改样式体系、入口与交互。
- 时间视窗：标题、档位、起止日及轴单位「线索数」。日期格式保留空输入提示和校验；矩阵默认不另写图注。新建/修正泳道工作面的专用图注与交互保留。
- 矩阵：单条「当日线索数（不含综合稿） · — 无分区 · ? 数据不可用」；仅跨出档窗显示「历史仅补数据，泳道名单不变」。日报落后时显示「日报截至 YYYY-MM-DD」，保留查看所选日。
- 右轨：评分、检查时间、评语、候选名单和追踪状态照旧；标题与简短入口标识用途；实际收编处说明历史不自动回填，体检详情说明最新快照，激活按钮保留。来源仅补「独立于时间视窗」。
- 原失败、重试、无数据、焦点与辅助技术标签继续有效。
