# test-cases: declutter-article-list-panel

> 测试单元 = 用户故事「我在阅读页扫一眼列表挑文章，需要时查处理状态与筛选」。层选择：组件渲染断言→Vitest；完整交互故事→opencli；视觉→双视口子代理（major 验收）。无白盒附加（complexity: simple，状态派生为三分支聚合已入组件单测，不构成状态机复杂档判据——划除留痕：状态机白盒附加不适用）。

## 变体走查

- **输入**：超长标题（>2 行）→ line-clamp 截断行高不漂移（Vitest）；超长错误文案 → 浮层内滚动不破版（Vitest）；空标题/空作者 → meta 缺项不渲染空占位（Vitest）
- **前置**：空列表 → 空态文案（既有保留）；单行列表 → 展开浮层不被列表底边裁剪（opencli 目检留痕）；全部文章视图 → meta 首位显示来源名（Vitest）
- **时间窗口**：日期筛选边界（当天含/不含沿用既有后端口径，本 change 不改查询语义——划除留痕：时间窗口变体不适用，纯展示层）
- **幂等**：重复点同一图标 → 开→关；快速连点两行 → 后开者胜、前者关（Vitest）；重复应用同一筛选 → 结果不变（opencli）
- **可用性**：空态（既有）/加载态（既有）/错误态=失败行红⚠可查因（Vitest）/加载更多→浮层开着滚动时随行移动不飘（opencli 目检留痕）

## 效果核对

不适用（无数据覆盖率/LLM 行为依赖——划除留痕）。
