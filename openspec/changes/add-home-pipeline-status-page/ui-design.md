## User Journey

**新人（空库）**：打开 `/` → 平台上只有 ① 信源港立着，其余八站只剩分区轮廓 → 一句「整条线在等第一个订阅源」→ 一个动作「添加订阅源」→ 加完回来，看着自己的源在 ① 落位、货箱在 ① 外的道路上排开、工人沿 ①→② 走。

**日常（有积压）**：打开 `/` → 3 秒内读到四件事：**卡在 ③ 打标（1084 篇排队 / 4 在岗 / 今天做完 156）**、**谁在干活（`topic_tagging`→Qwen3.5-4B、`embedding`→qwen3-embedding、`digest_polish`→deepseek-flash）**、**今天有没有出纸（0 份，最近 11-03）**、**积压长什么样（③ 入厂路外侧 11 只货箱）** → 想看队列点 ③，想读文章切阅读模式。

**出问题（暂停 / AI 断 / 失败 / 空转）**：打开 `/` → 断开的那一段**熄了**（④ 向量炉、③ 打标车间同时断电，底座亮起缺口弧），路变成灰色点线，诊断条一句话说清因果（例：「AI 未就绪：③④ 停摆，队列只增不减；② 抓取照常入库」）→ 一个修复动作。不用去设置页逐个翻状态。

**探索（想知道某个源 / 某个版块）**：点 ① 信源港 → 抽屉里 5 个文件夹 → 进「新闻」→ 12 个源（带文章数 / 上次抓取 / 报错标记）→ 点某个源看它的 RSS 文章。点 ⑦ 版块区 → 12 个街区（标签数、是否开数据增强）→ 去版块矩阵。

**换视角（想看全貌或细节）**：滚轮或面包屑 `全图 › 工坊岛 › 打标车间 › 检视` 逐级推近——**全图**看整幅巨幅地图（平台只是被红圈标出的一块地）、**工坊岛**看九站六区九路、**节点**看单站、**检视**看零件级细节。ESC 逐级退。

共同点：**先看图形（堵在哪、谁在动、堆了多少），再读字（多少、哪个模型）**。

## Interaction Contract

**只做六类交互：**

1. **四档变焦**：滚轮（每格 `viewH × 1.12`，屏幕空间线宽按 `min(1, worldPerPx() / (34/900))` 钳制）+ 面包屑 + 点站体。
   - `全图` → 平台缩成画面中央一块，被红圈标出；
   - `工坊岛` → 平台铺满画面；
   - `节点` → 相机 lerp `.10` 推到该站上方（`targetGoal = (x, 1.15, z)`），单站特写；
   - `检视` → `viewH = 4`，零件级；
   - 滚轮向上推近、向下拉远；`viewH < 6` 自动进 `inspect`，`≥ 6` 退回 `focus`。
2. **面包屑**：常驻，`全图 › 工坊岛 › 打标车间 › 检视`。**任意一段可点跳转**；`节点` 段显示当前站名；`检视` 段无当前站时禁用。ESC 逐级退（`inspect` → `focus` → `isle` → `map`）。
3. **hover 压图大标题 + 图钉**：悬停站体 → 站顶出现**图钉**（站名 + 主数字），**压图大标题**绝对叠在全屏画布上（衬线大字，86.4px 上限、.78 透明度），不另开面板、不占版面；hover 完整卡移到图钉侧方（偏移 `w/2 + 34`），避免为绕开图钉而跳过多栋建筑。
4. **点站体**：单击 → 进 `节点` 档；再点同一站 → 进 `检视` 档（`viewH ≥ 6` 才允许）。**不弹模态压住地图**。
5. **站点进门**：点站徽章 → 去「站点即门」表的位置；整卡是 `<button>`，Tab 顺序 = 编号顺序，focus-visible 有轮廓。
6. **钻取**（仅 01 与 07）：右侧抽屉，面包屑逐级回退；Esc / 点遮罩 / ✕ 都能关，焦点回到触发卡。

**硬约束：**

- 首页**只读**：任何交互都不得触发抓取 / 打标 / 成稿。
- 不弹模态压住地图；抽屉打开时地图整体压暗但保持可见（用户要知道自己在哪一块）。
- `prefers-reduced-motion: reduce`：画布 `noLoop()`，工人冻结在同一帧（仍在岗），虚线静止，**全部数字照常**。
- 数字必须与快照一致；拿不到的显示「—」并在副行说明原因，**不填 0、不估算**。
- 画布不承载文字与命中区：`aria-hidden="true"`，读屏只读 DOM 徽章与面包屑。
- 标签宁缺勿叠：站徽章冲突时先横向推开、再上下错层，最后夹回舞台内；实在放不下就跳过，**不得压字**。

## State Matrix

**节点状态互不排斥**。地图有 9 个站，用「整页一个状态」会撒谎——「③ 卡住」和「08 没版块」可以同时成立。

### 8 种节点状态

| 状态 | 含义 | 视觉 |
|---|---|---|
| `ok` | 有数据、不忙 | 正常墨色、实体亮面 |
| `flow` | 正在处理 | 实体亮面 + 信标呼吸（scale 1.0↔1.15 周期） |
| `idle` | 这一段没活 | 暗一档描边，数字比 `ok` 暗 |
| `queue` | 有积压（排队但没堵死） | 琥珀数字 + 琥珀信标 + 货箱转橙 |
| `jammed` | 堵死 | 琥珀，工人堆在站前 |
| `off` | 核心断点挡住（断电） | 填充色压暗 + **底座缺口弧 `#ff7a3d`**（暗色）/ 选中红圈（浅色）+ ⚡ 标记；连进来的路变灰点线 |
| `degraded` | 非核心能力断（降级） | 暗琥珀，**照走不停**，只打小标 |
| `empty` | 这一站还没有东西 | 半透明 + 徽章「—」 |
| `unbound` | 路由未绑定 | 描边虚线 + 无信标 + 「未配置」 |

> **故障只用底座缺口弧**（暗色 `#ff7a3d`）/ **选中红圈**（浅色 `#c0392b`）表达，**不铺红色装饰**。

### 工人 / 货箱与状态的联动

| 情形 | 工人 | 货箱 |
|---|---|---|
| `processing > 0` | 画 `processing` 个小人，朝工位站，**极缓慢错相位摇摆**（幅度 0.004 世界单位，周期 3~5 秒） | — |
| `processing = 0` | **工位空着**（小人淡出，不留残影） | — |
| `pending > 0` | — | 堆 `min(20, ceil(pending / 100))` 只箱，**1 箱 ≈ 100 篇**；两排静置在入厂道路端点外侧，**不压路、不压台基** |
| `queue` / `jammed` | 工人堆在站前 | 箱子转**橙色**（数据告警色，不是光源） |

> 图例必须写明两条换算：「· 小人 = 该站正在处理的篇数」「· 1 箱 ≈ 100 篇（超出 20 箱不再画）」。
> 真实例：打标 1084 篇 → **11 箱**；向量 255 篇 → **3 箱**。

### 核心断点

`coreHealthCapabilities = { embedding, topic_tagging }`（即 `ai.routes[]` 中 `capability` 属这两项的能力）。

| 断点 | 后果 |
|---|---|
| `embedding` 或 `topic_tagging` 任一不可达 | **优雅停**：③④ 断电（`off`），队列只增不减；② 抓取照常入库 |
| `summary` / `digest_polish` 等非核心断 | **降级**（`degraded`）：照走不停，只打小标 |

> 默认快照（2026-11-04 20:25）本机两断：`embedding` 与 `topic_tagging` 均 `reachable = false` → ③④ 断电。

### 诊断条优先级（自上而下首个命中）

| 序 | 条件 | 文案骨架 | 动作 |
|---|---|---|---|
| 1 | `feeds.total === 0` | 空库：整条线在等第一个订阅源 | 添加订阅源 |
| 2 | `ai.paused` | 分析已暂停：③④ 不接活，② 抓取仍在跑 | 恢复分析 |
| 3 | 核心能力不可达 | AI 未就绪：③④ 停摆，队列只增不减 | 去配 AI |
| 4 | `tag.failed > 0` | ③ 有 N 篇打标失败，等重试 | 看重试 |
| 5 | `articles.unarchived === 0 && feeds.total > 0` | 等首批 /（有源报错时）N 个源报错，② 空转中 | 看信源 |
| 6 | `boards.length === 0 && tag.completed > 0` | 标签打出来 N 篇，还没有版块接住 | 去建版块 |
| 7 | `boards.length > 0 && !report.latest` | 版块有了，还没成过一次稿 | 生成日报 |
| 8 | `tag.pending > 200` | 卡在 ③：N 篇排队、M 在岗，今天做完 K | 看队列 |
| 9 | `feeds.errors > 0` | N 个源抓取报错 | 看信源 |
| 10 | `content.failed > 0` | 正文补全 N 篇失败，维护任务会自动重试 | 看队列 |
| 11 | `!report.today` | 今天还没有日报；最近一期 X | 看日报 |
| 12 | 其它 | 全线正常：今天完成 N 篇打标、M 篇向量 | — |

> 判据来自 `/api/poll`（复用 `usePollBundle`：热态 5s、实际受 **≤4 次/分钟** 预算约束约 10–15s；失败保留旧值不清零）
> 与一次性拉取（`/feeds`、`/categories`、`/articles/stats`、`/content-completion/overview`、`/semantic-boards`、`/daily-reports/today`、`/annotations`）。
> 推导是纯函数 `deriveHomeMap(snapshot)` + `diagnose(snapshot)`，**不读 localStorage、不落库、不存 flag**。

### 边的状态

`flow`（在流动）· `jammed`（堵在这一段前面）· `blocked`（目标站停摆）· `idle`（这一段没活）· `degraded`（非核心断，照走）。

> **边表达「这一段在运转 / 堵住 / 停了」，不表达吞吐速率**。快照里没有「每秒处理几篇」，画出来就是编。

### 冷启动阶梯（只影响主 CTA，不影响节点状态）

空库 → 等首批 → 打标积压 → 没版块 → 没成稿 → 正常。一旦出过稿就稳定在「正常」，之后的积压只体现在 ③ 的数字与琥珀色上，**不会把首页打回「冷启动」**。

### 非状态性状态

| 情形 | 处理 |
|---|---|
| 接口失败 | 整页错误态 + 重试；不显示假数字 |
| 单项缺失 | 该站「—」+ 副行原因；其余照常 |
| 首次访问 | 不播讲解（旧版讲解播放器退役）；直接用当前真实状态 |
| 窄屏 | 走单栏列表态 / 阅读态互斥，**不隐藏任何站**（站信息进列表行） |

## Layout Contract

- **布局模式**：地图舞台按 **`workspace`**（填满可用宽度）落地，页面级 `overflow: hidden`，不滚动。**不是** `contained`——1120px 居中会把巨幅地图压成一条窄带，制图语言直接失效。该页属「固定视口栅格」形态（无页面级纵向滚动、仅舞台内缩放），**实现阶段须在 `docs/reference/standard/frontend/layout.md`「已登记例外」表登记一行**：change = `add-home-pipeline-status-page`，界面 = `/` 脉络地图，理由 = 制图作品需全幅、1440×900 一次看全，目标视口 ≥1440×900 / 1920×1080，溢出策略 = 页面 `overflow: hidden` + 舞台内缩放，回落规则 = <1440px 仍 workspace，<768px 走窄屏列表壳。
- **纵向预算（1440×900）**：工具栏 56 → 地图舞台铺满剩余全屏；**整页不滚动**。安全区：顶部 ≥84px（工具栏 56 + 呼吸），左右 ≥48px，底部 ≥48px。面包屑 / 图例 / 海报大标题 / 图框 / 插图全部叠在画布上，**不占文档流高度**。
- **画布 vs DOM**：画布绝对定位铺满舞台（`position: fixed; inset: 0`），只画地形 / 地块 / 道路 / 站体 / 工人 / 货箱；站名徽章、分区标签、面包屑、图例、海报大标题是 DOM 绝对定位层，**尺寸固定、字不缩放**。两者共用同一份屏幕坐标（由 `camera.project()` 现算，1:1）。
- **巨幅地图（v50 起）**：平台外不是水，是**巨幅地图**——40 块共边排线地块（八色色板分层）+ 8 条外围双线乡道 + 89 棵路旁树符号 + 溪流 + 图框 + 坐标网格（横 0–7 / 纵 A–F）+ 比例尺 + 右下插图小地图。**平台只是被红圈标出的一块地**。
- **图框与坐标**：外围图框为双线；横坐标 0–7、纵坐标 A–F 的网格线用浅墨色，不与数据流路混淆。
- **比例尺**：图框下方一根带刻度的比例尺条，标出当前档的世界单位跨度。
- **插图**：右下角小地图（SVG inset，用**真实站点与道路采样**绘制，可点选平移）+ 地块档案框。
- **红圈**：全图档只有**一处**红色——`#c0392b` 圆圈标出平台（`#map-marker`），其余全部墨色；不许多处红。
- **LOD 阈值**：`viewH > 70` → 0 站徽章 + 0 分区标签 + 1 个聚合标签（`9 站 · 28 源 · 3516 挂载`，走真实快照）；`40 < viewH ≤ 70` → 只显站名；`viewH ≤ 40` → 完整徽章；节点档 → 只显当前站。
- **线宽**：`widthScale = min(1, worldPerPx() / (34/900))`——屏幕空间恒定，但超过基线后停止增长，远景线路随地图一起缩小（否则线路比建筑还粗）。map / isle / focus 实测 **10px / 30px / 30px**。
- **色彩**：浅色 / 暗色两套固定色板（见 Information Architecture），不与产品 token 拼色。画布从探针元素读令牌（`getComputedStyle` 对自定义属性返回未展开 `var()`，必须落到真实元素上求值）。
- **动效与布局解耦**：画布每帧只重绘像素，不动 DOM 尺寸；徽章过渡只碰 `border-color / transform / opacity`。
- **画布 1:1**：canvas 尺寸 = 舞台 `clientWidth/Height`（乘 DPR），resize 重排重绘；站点卡不得互相覆盖；断点统一 `767.98px`。
- **窄屏**：`<768px`（`@media (max-width: 767.98px)`）**不渲染 3D 画布**，走**单栏列表态 / 阅读态互斥 + 订阅源抽屉**（真实 `FeedLayoutShell`），**不是三栏并排**；海报层 / 图框 / 插图 / 面包屑 / 图例全部 `display: none`。≥768px 视口布局与交互**零变化**（窄屏降级不外溢）。
- **双视口验收**：1440×900（无页面级滚动、无横向溢出）与 1920×1080（无横向溢出）；窄屏 375×667 / 390×844 无 canvas、无破版。
