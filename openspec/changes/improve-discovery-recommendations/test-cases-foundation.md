## 白盒分支与边界

- URL仅http/https，拒绝空、空白、相对路径、userinfo、无host、非法端口；host小写，path大小写和query原样，fragment移除，http:80/https:443移除。
- URL 499/500字符接受，501拒绝（不按字节截断）；名称199/200接受、201拒绝；描述3999/4000接受、4001拒绝。Unicode按rune计数。
- 不做网络请求；纯逻辑不得解析DNS或创建Feed。
- 手动字段非空优先，空覆盖恢复上游；缺上游与缺人工两者不编造资料。
- 稳定键不能包含数据库ID、source请求类型或时间。
