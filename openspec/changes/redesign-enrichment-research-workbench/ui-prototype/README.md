# 研究工作台规划原型

- `index.html`：已认可的主从/正文基线，补齐忽略恢复、任务入口、版本位置、重研确认、话题背景与全部旧历史。
- `states.html`：loading/empty/error/running/disabled/long/bad-report等检查入口；不是产品新增页面。
- `prototype-extra.js`：可丢弃浏览器内存交互；无API/LLM/业务库访问。正式代码不能照搬此DOM脚本。
- `evidence/`：1440、1920、390视口及历史/背景补充截图；375窄屏另做无溢出断言。只证明原型，不是实现验收。

用户于2026-10-15明确选择「批准 UI，继续规划」。阶段仍是规划，未开始实现。

## 打开和差异

本目录下载/保留在一起，浏览器打开 index.html。报告样例为截图材料重编，原值不代表重新取数；价格原单位没有补造。

原型只在内存记录忽略，刷新复原；正式服务端须持久化。版本选择演示位置，不真实读取不同result_id；话题总览按钮直接模拟选中话题后的背景目标，不重建整套现有浏览器。正式组件用AppPageShell/AppDialog等基础组件，不照搬原型的页面CSS、原生dialog或未保存草稿简化行为。

## 已做的原型检查

脚本语法、忽略后报告仍可读、恢复、五类旧结果、问答无输入框、背景编辑、研究中禁忽略、跨周期继续阅读和返回任务、列表失败后GET式重试、1920/1440/390/375无整页横向溢出、窄屏历史弹窗92vw内、无运行时错误。一次脚本在窄屏详情中尝试点击已隐藏的索引历史按钮，已修正为先返回索引再打开历史并复查通过；这不是产品实现修复。

检查后均关闭本次命名浏览器，没有启动预览服务。真实实现仍必须按ui-design Acceptance与test-cases进行独立验证。
