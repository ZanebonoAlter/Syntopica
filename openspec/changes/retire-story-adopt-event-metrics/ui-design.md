# 事件线退役的 UI 复用合同

> 本次只替换既有面板里的**口径与内容**，不新建页面 / 不新建独立面板 / 不引入新交互流程：雷达首屏、版块态势矩阵、日报阅读台刊头三处沿用现有结构与既有交互模式，故 ui-impact=minor，approval=not-required，prototype=none。

## 入口与入口变更

## 复用组件与布局模式

- 不新建页面，沿用既有 console workspace（`BoardConsoleShell` / `BoardRadarView`）与日报阅读台两栏结构；不引入新布局模式，也不改既有栏宽与断档规则。
- 雷达右栏沿用既有清单行结构（版块名 + 计数 + 可选徽标位）；本次**移除**徽标渲染分支，保留行结构与空态组件。
- 矩阵格沿用既有格渲染与主题色阶（`--color-accent` mix `--color-bg-base`，经 CSS 变量注入）；色深按当日线索合计做行内归一连续深浅（`clueDepth`），不恢复 `.b1..b4` 四档，数字样式与 `title` / `aria` 不变。
- 刊头「今日重点」沿用既有刊头边框语言与要闻条目行；定位按钮沿用既有按钮与高亮计时器（2s、reduced-motion 不平滑滚动）。
- 配置字段沿用既有「匹配规则」弹窗的 `AppDialog`（`size="lg"`，760px、92vw 上限）与既有输入控件、错误提示与保存链路，不新造弹层、不自由设宽度。
- 日报重点依据文案沿用既有可读提示样式；长标题 ellipsis + 完整 title。

## 修订记录

- **2026-11-11 用户看版后**：矩阵色深按线索数回归——工坊观察矩阵日格与雷达行内小矩阵的色深改为「当日线索合计在本行可见窗内归一」的连续深浅（0 = 底色、行内最大 = 最深、线性插值；跨行不归一），数值 + `title` / `aria` 仍为唯一信息承载，`clueCount` 为 null 不着色。原「颜色通道退役 / 取消色阶通道」口径由本条覆盖。
- **2026-11-11 用户看版后（第二次）**：滞后版块沉底弱化——右栏「当天线索最多的泳道」排序改为**锚点日新鲜度优先**（条目锚点日 = 全局锚点日者在前，滞后条目沉底）再按当天线索数降序，滞后条目灰显并标「数据至 MM/DD」；雷达列表滞后版块的「热点 / 关注」分档徽标撤除，改中性「数据至 MM/DD」，关注度数值照实显示（沉底/弱化不是折扣，不引入时间衰减）。原「各条目按自己的锚点日计、新旧同列混排」的呈现口径由本条覆盖。
- **2026-11-11 用户看版后（第三次）**：今日重点条目可展开列簇内全部线索——默认收起，前端用 `highlight.tag_ids`（缺省回退 `cluster_id`）与正文 thread `tag_ids` 求交集现算，按正文 DOM 序列出并标注所属话题名，命中代表标签的线索置顶标「代表线索」；行点击以 `{clusterId, threadId}` 精确定位该条 thread，空匹配显示「本期正文未找到对应线索」，条目主体点击与 `?cluster=` 深链仍定位 DOM 首条。同轮核对矩阵「当日其他话题」组计数：徽标改为**组内线索合计**（与矩阵主行格值同口径），分区数只留在「N 个分区未入泳道」说明文案里。原「重点只能定位 DOM 首条、其他话题组徽标 = 分区数」的呈现口径由本条覆盖。
