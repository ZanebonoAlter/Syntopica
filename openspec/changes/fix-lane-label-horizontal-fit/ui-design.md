# ui-design · fix-lane-label-horizontal-fit

- ui-impact: **minor**（复用既有画布与节点契约，只调横向布局参数）
- 参考契约：`docs/reference/standard/frontend/layout.md`「画布类工作面必须按容器真实像素 1:1 绘制」

## Interaction Decisions

无新增交互。缩放、选中、加入/移出、节点卡全部沿用既有契约。

## Layout Contract

- **布局模式**：`workspace`（既有），画布继续 1:1 像素绘制。
- **横向溢出策略（本次新增）**：画布宽 SHALL = `max(视口宽, 时间轴左缘 + 列宽 × 天数 + 右留白)`，
  其中列宽 ≥ 64px。列宽被下限撑开时画布宽 > 视口宽，由 `.lcc-surface` 的
  `overflow: auto` **横向滚动**承接。
  - 这**不违反** 1:1 绘制要求：`viewBox` 宽 = 画布内容宽，SVG 元素宽同值，无缩放；
    宽度随容器实测与天数**响应式重算**，不是挂载时算死。
  - 目标视口：1440×900（30 天档画布 ≈2098px → 横向滚动 ≈1.5 屏）；7 天档不滚动。
- **纵向**：沿用 `fix-lane-row-gap-zoom` 的行距与分区自适应（行距 44px）。

## 受影响状态

| 状态 | 是否受影响 | 变化 |
| --- | --- | --- |
| success（7 天档） | 是（轻微） | 列宽 ≈103px ≥ 下限，行为与旧版一致；标签每行 8 字 |
| success（30 天档） | **是** | 列宽 24 → 64px；画布 ≈2098px，出现横向滚动条；标签每行 5 字 |
| success（90/365 天档） | **是** | 画布进一步变宽（列宽恒 64px），横向滚动距离变长 |
| 空态 | 否 | 无节点即无标签，列宽变化只影响时间轴刻度密度 |
| 选中 / 节点卡 | 否 | 卡为绝对定位浮层，不参与列宽 |

## Data Provenance

无新增数据展示项；列宽与服务数据无关。

## 视觉与动效下限

- V1/V2：沿用既有 token，无新色值。
- V3/V4：焦点与键盘路径不变（画布既有声明）。
- V5：无新增动效。
- V6：无新增装饰元素。
