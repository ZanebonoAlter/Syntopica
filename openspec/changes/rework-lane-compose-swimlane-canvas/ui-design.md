# UI 设计契约 · rework-lane-compose-swimlane-canvas

> 主要模式为 **`canvas`**（新建泳道编排工作面是全屏画布工作台）→ 原型 SHALL 用 `ui-prototype/states/` 三态图 + `ui-prototype/interaction-table.md`，**SHALL NOT 用可点 HTML 模拟**。
> 审批流：major 初始 `pending`；用户在对话中明确确认后才改 `approved`。改变信息架构、主流程或布局模式的修订 MUST 重置 `pending`（颜色微调 / 文案修正记录差异即可，不重审）。
> 三态图：`01-empty.svg`（空态）/ `02-editing.svg`（编辑中）/ `03-confirmed.svg`（已确认）；辅助态 `04-search.svg`（检索态）。同尺寸 1440×900，同结构，逐态对账见 `interaction-table.md`。

## User Journey

**入口**：版块控制台（`workshop-board-console`）→「新建泳道」→ 全屏编排面（`BoardComposeOverlay` 承载，不变）。

**主任务**：在给定时间窗口里，把「一条跨天主题叙事」拼出来并命名成泳道。

| 阶段 | 用户问题 | 界面给的答案 |
|---|---|---|
| 进场（阶 0） | 「这窗口里有什么？」 | 4 条候选链行 + 一条空的「本次泳道」行；散料收起（「另有 N 条未展开」） |
| 挑料（阶 1） | 「这条链要不要？还差什么？」 | 拖行标签 = 整组采纳；拖点 = 单条；原行留空位，行尾给 `n/N` |
| 补料（阶 1+） | 「还有哪些相关的？」 | 质心激活后散料按接近度浮现（大小/深浅），阈值三档可调 |
| 定向找料（阶 2） | 「我记得有一条讲 X 的」 | 右栏「按标题找」→ 画布切检索态，命中点四角括号浮出，逐条拖入 |
| 收工（已确认） | 「够了吗？能建了吗？」 | 覆盖度汇总（跨度 / 成员 / 断档）+ 「起名并创建」 |

**次任务**：调阈值看更多散料；展开散料地板；查看只读参照（已有泳道）；hover/点击读单条事件全文。

## Information Architecture

```
编排面（全屏，三栏 + 顶部两条）
├─ 顶部栏：返回 · 标题「新建泳道」 · 时间视窗档位 · 起止日 · 应用范围 · 状态标记
├─ 池曲线条：365 日线簇数（既有，只读，切窗口用）
└─ 主体三栏
   ├─ 左栏 300px｜候选泳道：10 条候选组（组头 + 勾选态 + 事件列表）
   ├─ 中栏 1fr  ｜画布（纵向四层，同一时间轴）
   │   ├─ 画布工具条：显示已有泳道（只读）· 阈值三档 · 溢出提示
   │   ├─ 日期轴 + 列 guide
   │   ├─ 泳道行区（y 有含义）
   │   │   ├─ 本次泳道（第 0 行，accent，落点）
   │   │   ├─ 候选链 1..N（中性，行尾 n/N；采纳完的折成一行摘要）
   │   │   └─ …
   │   └─ 散料地板（更小更淡；折叠时是虚线堆叠 + 「另有 N 条未展开 · 展开」）
   └─ 右栏 320px｜本次泳道检视（**骨架恒定，三段常驻**）
       ├─ ① 当前事件的线索   —— 空态：「尚未选入事件」；已确认态：换成「覆盖」汇总
       ├─ ② 可补充的事件 N 条
       ├─ ③ tab 区 [已选事件] [按标题找]  ← 任何态都在，检索入口不得消失
       └─ 起名并创建
```

**右栏骨架自洽约束**：① ② ③ 三段在空态 / 编辑中 / 已确认 / 检索态**都渲染**，只换内容不换骨架。空态下 ③ 默认落在「按标题找」（此时没有已选事件，空列表无意义，唯一动作就是找料）；编辑中与已确认态 ③ 默认落在「已选事件」。检索态 = ③ 切到「按标题找」+ 画布降级，**不是**另一套右栏。

**节点文字档**：候选链成员与本次泳道成员在点下常显 ≤10 字截断标题（**字号 11px**，居中对齐点）；**常显永不因列宽关闭**——放不下时由画布横向滚动解决，不缩字（2026-11-21 用户改档，见 `Layout Contract` 几何变更）。未归属散料**不常显标题**（母 spec 既有）。检索态的命中点例外（结果呈现需要辨识）。

**同日多节点**：竖直堆叠，每槽 24px（点 9px + 标题 10px + 间距），行高随当日条数增长。不做折叠计数点 —— 同一天多条要能各自看到标题。

**层级判据**：画布的纵向维度从「同日内 `id` 序号（无含义）」改为「**所属候选链**（身份）」，因此「行 = 泳道」——产品名第一次在画面上成立。

## Interaction Contract

### 主操作

| 操作 | 手势 / 触达 | 反馈 |
|---|---|---|
| 单条选入 | 拖节点 → 本次泳道行 → 松手 | 拖起 ghost 放大跟随；源位留虚线圈；目标行高亮（accent 微底 + 虚线框）；松手吸附到该日期槽位并变实心 + ✓ |
| 整组采纳 | 拖候选链**行标签**（左侧名称区）→ 本次泳道行 | 该行全部成员一起半透明跟随；松手后整行未采纳成员同时落位 |
| 移出 | 拖本次泳道成员 → 行外松手 | 节点变回空心并回到原行；toast「已移出 · 撤销」（3 秒） |
| 起名并创建 | 右栏底部按钮 → `AppDialog` size=md | 名称 + 「N 条事件」；确认后退出编排面 |

> **本次泳道不绑定候选链**：成员可以来自任意链与散料（同一话题下跨链很常见）。因此：某条链的成员被取空 → 该行直接消失（左栏仍记 `n/n`）；**不出现**「已采纳」摘要行，**不统计**来源构成。候选链在这里只是素材来源，不是本次泳道的身份。

### 次操作

- **点击节点 = 只看**（钉住节点卡），**不改成员数**；取消：点空白 / Esc / 卡上 ×。
- 阈值三档：只改散料显隐；画布与右栏「可补充的事件」同批。
- 展开/收起散料地板。
- 平移 / 缩放（空白拖 / 滚轮，0.5×–3×）。
- hover 节点出卡（既有）；hover 行标签显示可拖动光标 + 该行成员同时提亮（整组拖动的可拖提示）。

### 危险操作

| 操作 | 保护 |
|---|---|
| 移出成员 | 拖拽本身是高意图手势；额外给 3 秒 toast 撤销（**不弹窗**，`spec` 既有「取消勾选为破坏性动作」不加确认） |
| 取消本次（丢弃草稿） | 沿用既有 `compose.cancel()` 的确认口径 |
| 创建泳道（写库） | 名称为空白拒绝创建并保留成员（既有口径） |

### 失败与恢复

- 拖拽越出画布 / 窗口失焦 / `pointercancel` → 取消拖拽、节点回原位，无副作用。
- 创建失败 → 留在编排面，成员与已写名字不丢，错误在对话框内。
- 候选链取不到 → 画布留空态行，不画空行。

| 数据项 | source | 说明 |
|---|---|---|
| 候选泳道组与事件列表 | api `/api/semantic-boards/:boardId/persistent-topics/compose-candidates` | 左栏 10 条，含组内事件标题与日期 |
| 候选链（行 + 成员 + 跨度） | api `/api/semantic-boards/:boardId/persistent-topics/compose-candidates` | 服务端唯一口径；前端只渲染，不重算候选资格 |
| 成员日期位置（x） | 派生 `periodDate → dateIndex` | 窗口内按日等分列 |
| 行归属位置（y） | 派生 `所属候选链` | 同日内排序键由 `id` 改为链归属；散料入地板行 |
| 节点大小 / 深浅（接近度） | 派生 `1 − cos(已选成员质心, section.embedding) / matchThreshold` | 前端 `laneComposeLogic.centroidRecommendations`；仅未选散料与推荐点编码 |
| 阈值档位（0.3 等） | api `compose-candidates` 响应 `matchThreshold` | 三档映射到该值的收紧/放宽 |
| 折叠计数「另有 N 条未展开」 | 派生 `窗口内散料总数 − 当前档位可见数` | 数值 + 动作，不含解释句 |
| 本次泳道成员（草稿） | 前端会话态 | 编排全程不落库 |
| 检索命中集 | 派生（本期：前端按标题过滤**未归类**节点） | 口径 = 不属于画布上任何候选链的节点（含未归属话题 + 挂着 candidate 话题但未成链）；**不含**候选链成员。后端检索能力（正文/摘要）单独立项 |
| 覆盖天数 / 断档 | 派生（成员日期集合） | 仅在已确认态展示；**不统计来源构成**（跨链成员是常态） |
| 创建泳道 | api `POST /api/semantic-boards/:boardId/persistent-topics/manual` | `label` + `section_ids`；唯一写操作 |
| 顶部池曲线（线簇数） | api `/api/semantic-boards/:id/lane-dynamics?days=N` | 既有，本 change 不改 |
| 只读参照（已有泳道） | api `compose-candidates`（`showAssigned` 分支） | 既有，本 change 只把默认开关与呈现位置调整 |

## 明确不做

- 画布上**不出现**按话题/事件着色的节点或行（归属只用位置表达）。
- 画布上**不出现**表示行跨度的横条胶囊（横向位置已由成员自身表达；行分组靠 y 区段 + 行标签 + 分隔线）。
- 画布上**不出现**图例、教学句、口径长句（「接近度不是置信度」这类解释不进界面）。
- 画布上**不出现**节点编号（全局序号 01..N 下线；行尾的 `n/N` 是采纳计数，不是节点编号）。
- 画布上**不出现**「已采纳」摘要行或来源构成统计（本次泳道不绑任何候选链）。
- 画布上**不出现**同日折叠计数点（`●3`）。
- 30 天窗口下常显标题**照常出现 11px**，画布横向滚动（不整档关闭、不降级成 2 字碎片）。
- 画布上**不出现**搜索输入框（检索入口只在右栏 tab）。
- 画布上**不出现**跨泳道的长 tick 拖线（成员直接排在所属行内）。
- 画布上**不出现**「选入全部命中」这类批量按钮（检索态逐条拖）。
- 右栏**不出现**关联事件清单、计算依据折叠、话题泳道参照。
- 节点卡上**不出现**接近度之外的派生解释（无质心公式、无事件线身份数）。
- 散料节点上**不出现**常显标题（读全文靠 hover 卡）。

## State Matrix

| 状态 | 触发 | 画布 | 左栏 | 右栏 | 恢复路径 |
|---|---|---|---|---|---|
| **loading** | 进入编排面 / 切窗口 | 画布区留骨架（日期轴 + 工具条在位，不画半截泳道），不出现跳动重排 | 组列表骨架 | 空白三段标题在位 | 自动；失败转 error |
| **empty（无数据）** | 窗口内 0 条事件 | 「这个范围内没有可画的事件。换个范围，或在右栏『按标题找』里补。」（既有文案） | 「0 条」 | 「尚未选入事件」 | 改范围 / 切档位 |
| **empty（有数据但全折叠）** | 阶 0 且散料全被阈值收起 | 只画候选链结构 + 空本次泳道行 + 地板「另有 N 条未展开 · 展开」 | 正常 | 「尚未选入事件」 | 展开地板 / 选入一条激活质心 |
| **empty（无成型候选）** | 窗口内无合格候选链（节点 <2 或首末日差 <3） | 只画空本次泳道行 + 地板（全部散料），顶部提示「这个范围没有成型候选」 | 候选组为空态文案 | 「尚未选入事件」 | 换更长窗口 |
| **error（候选链取数失败）** | API 失败 | 画布留空态行，不画空行；不显示折叠计数（避免假 0） | 组区行内错误 + 重试 | 「尚未选入事件」 | 重试 |
| **error（创建失败）** | 创建接口 4xx/5xx | 不变 | 不变 | 对话框内错误，成员与已写名字保留 | 改名字 / 重试 |
| **success（编辑中）** | 已选 ≥1 | accent 行标签 + 成员（实心 ✓）；散料按阈值浮现；地板折叠计数 | 组尾 `n/N` | 当前事件 + 可补充（与画布同批） | — |
| **success（检索态）** | 右栏输入非空 | 候选链层 22% + 命中四角括号浮出；本次泳道行不降级 | 不变 | tab 切「按标题找」+ 命中列表 | 清空 / Esc |
| **success（已确认）** | 成员定稿 | 行标签换成新名字；取空的候选链行消失（不留空行）；地板折叠 | 组尾 `n/n` | ① 换成「覆盖」汇总；② 0 条；③ 已选事件 12 条 | 起名并创建 |

## Layout Contract

- **layout mode**：`workspace`（沿用母 spec 既有三栏 `300px / 1fr / 320px`，本 change **不改**栏宽与溢出策略）。
- **目标视口**：桌面 `1440×900`、`1920×1080`。两档均要求 `documentElement.scrollWidth === clientWidth`（无横向溢出）、三栏不破版、日期轴标签不越界。
- **窄屏**：`< 768px` 回落为既有整屏提示「新建泳道需要宽屏或横屏」，不渲染残缺画布。
- **画布内几何约束**（继承 `standard/frontend/layout.md` 渲染保真节，不变）：SVG 与 CSS 像素 1:1；文字/行标签/节点框不得越出画布边界；标签冲突**宁缺勿叠**；节点渲染半径下限 3px（只读 2.5px）。
- **对话框**：命名对话框 `AppDialog size="md"`（560px，92vw 上限）——沿用既有，本 change 不新增对话框。
- **本 change 新增的几何**：每条泳道行占固定纵向区段（行标签 32px + 成员槽位 **24px**/条 + 行间 26px，行间用 1px 分隔线）；本次泳道行预留 2 个槽位高度以便落点。散料地板收起时 112px。

### 几何变更（2026-11-21 用户当场批准 · 可读性提档）

来源：用户在 30 天窗口实拍后指出「节点全是同款小圆点、文本看不清」。两项决定（已确认选项，非自由发挥）：

| 项 | 旧 | 新 | 依据 |
| --- | --- | --- | --- |
| 时间列宽 | `span / 天数`（30 天 ≈ 23px） | `max(52px, span / 天数)`，不足即**横向滚动** | 52px 是 11px 字号放 4 字的下限 |
| 节点直径 | 散料 4.8–8.4 / 推荐 ≤已选 6–10.8 | 散料 **11px** / 推荐 12.4–14px / 已选 **15px** | 15px 圆内放得下 ✓ |
| 常显标题 | 8px，列宽 <40px 整档关闭 | **11px**，最多 10 字，节点下方 14px，**永不关档** | 8px 是"看不清"的主因 |
| 同列堆叠槽距 | 24px | **保持 24px**（试过 18，几何不成立：标题下缘 y+15 vs 下一槽圆顶 y+slot−7.5 → slot 须 ≥22.5） | 11px 标题与 15px 直径共同定下界 |
| 事件关系边 | 画原关系边（identity 实线 / similarity 虚线 4 4） | **删除**（spec 早已写「不生成事件关系边」，实现超纲） | delta spec:152 / 主 spec:142 |
| 吸顶 | 仅本次泳道行纵向吸顶（P-1） | 纵向吸顶（本次泳道行 + 日期轴）+ **行标签列横向吸顶** | 横向滚动后标签必须常驻 |

**横向滚动的几何口径**：内容宽 = 行标签 132px + 天数 × 列宽 + 右留白 24px；`overflow-x` 出现时日期轴停在顶部、行标签列钉在最左（不透明底 + 与纵向吸顶同款 6 级渐隐阴影），时间轴随内容横向移动。
**验收锚点**：1920 视口下 30 天 = 1560px 内容宽 vs 1114px 可视 → 必然横向滚动；14 天 = 728px → 不滚动。1440 视口下 14 天 = 728px vs 664px 可视 → 横向滚动。
- **本次泳道行吸顶（P-1 修复，变更来源：用户 2026-11-21 选方案 1）**：当候选链行数使画布内容高度超过可视高度时，画布纵向滚动，**第 0 行「本次泳道」SHALL 钉在画布顶部不随滚动移动**，其下 SHALL 有 1px 分隔 + 阴影表达层界。理由：拖拽的唯一落点是第 0 行，若它随滚动移出视口，「从地板拖入本次泳道」在链数 ≥6 的窗口里物理不可完成（实测 board 3030 @30 天：内容 1076px / 可视 505px）。
- 吸顶行 SHALL NOT 遮住日期轴：日期轴留在吸顶行之上；吸顶行 SHALL NOT 参与画布纵向滚动。滚动区从吸顶行下缘开始。

## Component Reuse

### L2 交互沙盒（补充制品，非合同）

- 路径：`ui-prototype/sandbox/index.html`（单文件、零依赖、`file://` 直接打开）。
- 用途：只在实现前验**手势手感**（拖单点入行 / 拖行标签整组 / 拖出移出 + 撤销 / 阈值三档 / 检索态 / 同日堆叠 / 点击只出卡）。
- **不构成验收基准**：`ui-design-gate` 的 marker 仍指向 `ui-prototype/states/01-empty.svg`；harness 比对基准仍是三态图逐态 + `interaction-table.md` 逐行。
- 偏离声明：`.pi/extensions` 的 ui-design 规范写「canvas 主模式 SHALL NOT 用可点 HTML 模拟」；本条由**用户 2026-11-20 明确要求**（"把可交互原型也出了"）触发，按 `AGENTS.md` 优先级宪法（用户当场指令 > 规范）执行，并在此留痕。
- 沙盒**未模拟**：画布平移、滚轮缩放、真实接口——这三项在实现时才定型，沙盒里的手感不代表最终行为。

## Acceptance

实现后补，证据以 `ui-verification/report.md` 建账（`### A-N 场景【pass|fail|未覆盖】+ 依据行`）：

| 编号 | 场景 | 判据 |
|---|---|---|
| A-1 | 进入编排面（阶 0） | 只出现候选链行 + 空的本次泳道行；散料默认折叠且有「另有 N 条未展开」；无编号、无图例、无着色 |
| A-2 | 拖单点入本次泳道 | 成员数 +1；原行留空位；节点变实心 + ✓；右栏同批更新 |
| A-3 | 拖行标签整组纳入 | 该行全部未采纳成员一次落位；左栏记 `n/n` |
| A-4 | 拖出 + 撤销 | 移出后 toast 出现；3 秒内撤销可回原槽位；超时后不可撤销 |
| A-5 | 点击节点 | 只出节点卡，**成员数不变**（显式断言，防回归到"点击选入"） |
| A-6 | 阈值三档 | 只改散料显隐；候选链成员 / 已选 / 只读参照数量不变；右栏与画布同批 |
| A-7 | 检索态 | 候选链层降透明；**命中只来自未归类层**（候选链成员不可能命中）；命中四角括号 + 标题浮出；零命中时不浮出 |
| A-7b | 检索口径 | 输入一个只出现在某候选链成员标题里的词 → 命中 0（证明范围已收窄到未归类） |
| A-8 | 键盘通道 | Tab + Enter 可完成「选入 / 移出」，focus-visible 环可见 |
| A-9 | 双视口 | 1440×900 与 1920×1080 均 `scrollWidth === clientWidth`，日期轴标签不越界，三栏 300/1fr/320 不破版 |
| A-10 | 与原型对账 | 三态图逐态对账 + `interaction-table.md` 逐行对账；重大差异需重新审批 |
| A-11 | 节点标题档 | 所有窗口列宽均 ≥124px，常显 11px ≤10 字标题；散料始终无常显标题；30 天横向滚动 |
