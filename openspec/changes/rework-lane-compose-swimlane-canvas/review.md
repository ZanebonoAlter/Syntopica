# Review 台账 · rework-lane-compose-swimlane-canvas

本 change 的审查分两条线：① 子线程独立 review（`change-review`，模型 `zai-coding-cn/glm-5.3:max`）；
② 用户实拍反馈驱动的缺陷回归（每轮都先修再验）。下面按时间序建账。

### R-1 2026-11-20【High】审查：六条红线复核

- **状态**：已修复
- **发现**：审查判「有条件通过」——六条红线（点击不改成员数 / 阈值只门控散料 / 折叠可展开且措辞合规 / 检索范围=未归类 / 不绑事件线 / 不画横条胶囊）全部 pass；但被修改的 4 条既有断言（V3/V6/V7 合同换血、V10 阶 0 散料折叠）需确认是否属于「改测试迁就实现」。
- **处置**：逐条核对为**合同变更**而非迁就——V10（阶 0 无质心时散料全收起）是有意设计，避免伪造达标；另 3 条随 Requirement 重写一并更新。结论记入 `design.md` D1–D9。

### R-2 2026-11-20【Medium】审查：驳回「节点标题偏移 0.6px」建议

- **状态**：已驳回
- **理由**：建议把标题基线上抬 0.6px，但该偏移与**已批准的 `ui-prototype/states/*.svg`（1440×900 几何基准）**一致；上抬会破 24px 槽距下的行间留白。审查方接受驳回。

### R-3 2026-11-21【High】实拍：画布纵向滚动致拖拽主手势失效（P-1）

- **状态**：已修复
- **发现**：30 天窗口内容高 1076px / 可视 505px，拖拽目标（本次泳道行）滚出视口，主手势不可用。
- **处置**：用户选「吸顶」方案 B（单层 SVG + 第 0 行整组反向 `translate(0, scrollTop/zoom)`，保住 1:1 像素契约、无第二原点）。组件测试 6 条含反向验证（删吸顶分支第 3 条立刻红）+ 部署后实拍（lane top 395 不动、首条链行 533→133）。

### R-4 2026-11-21【Medium】实拍：右栏②空态是机制科普（P-2）

- **状态**：已修复
- **处置**：`选入候选后，这里按成员平均质心给出可补充的事件。` → `无`；顺带清掉同文件 `选入/移出在画布上的节点卡里直接点。` 与 `跨正式泳道移入需另行确认`。撞 `standard/frontend/interaction.md` 的禁教学语条款。

### R-5 2026-11-21【High】实拍：画布画了事件关系边（P-3，实现超纲）

- **状态**：已修复
- **发现**：delta spec:152 / 主 spec:142 早已写「不生成事件关系边」，实现却渲染 `<g class="lcc-canvas__edges">` + `edgePath()`。
- **处置**：删边（含 CSS 与测试），原关系只保留「节点卡条数 + 相关标题」通道。

### R-6 2026-11-22【High】实拍：吸顶带文本重叠 + 关联度映射失效（P-5）

- **状态**：已修复
- **发现**：① 吸顶底色 rect 用 `y=0`（内容坐标），而行整组被平移 `scrollTop` → 底色落在视口上方，滚上来的行标签叠在吸顶文字上；诊断被裸 `<template>`（子节点 `getBoundingClientRect()` 恒 0）误导。② 尺寸提档后推荐半径区间被压成 `6.57–7.0`（0.43px），肉眼等于常量。
- **处置**：底色改 `y=-scrollTopLogical`；裸 `<template>` 改 `<g>`；标签移入置顶覆盖层；刻度/guide 加 `clipPath`（左界 = 可视区 `LABEL_W`）；推荐半径与填充改显式区间（`recommendRange {5.9,7.4}` / `strengthRange {18,80}`）。实拍：rect 高 438、`elementFromPoint` 命中自身底色；半径 46 档。

### R-7 2026-11-23【High】实拍：关联度仍看不出差别 + 标题随机出现（P-6 / P-7）

- **状态**：已修复
- **发现**：① 距离 0.59–0.67 与阈值同量级，`1 − d/threshold` 只剩 0.04–0.14；② 标题只给「候选链/已选/检索命中」，同一行里与「是否相关」绑定 → 看着随机；③ 列宽 52px 下标题只有 3 字。
- **处置**：接近度改**批次内相对归一**（min-max，单点/全等取 0.5）；标题口径统一为「所有会画出的节点都常显，放不下整条不画」；列宽下限提到 124px、标题 ≤10 字、截断改宽度口径（`truncateByWidth`）；折叠计数改「低相关散料 N 条 · 展开」；删除画布底部说明行。实拍：半径 46 档（5.90–7.50）、散料行 43 节点 / 43 标题。

### R-8 2026-11-23【Low】实拍：槽距 18px 与 11px 标题几何冲突

- **状态**：已修复
- **发现**：子线程按 18px 实现，但「标题下缘 y+15」与「下一槽圆顶 y+slot−7.5」要求 slot ≥22.5，18px 必然压字约 5px。
- **处置**：槽距回到 24px 并同步测试期望；`floor-fold` / `row-more` 加 `rowLabelTransform`，避免横向滚动后控件滑到吸顶列下方点不到。
