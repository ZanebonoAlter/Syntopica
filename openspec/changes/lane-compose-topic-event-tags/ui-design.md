## 入口与入口变更

- 入口：版块控制台 → 新建泳道编排态（`BoardComposeOverlay.vue` 承载，不变）。
- 变更点（均为**纯展示补充**，不改任何选择/推荐计算）：
  1. 画布话题带标题行（`LaneComposeCanvas.vue`）：标题后追加 ★ 徽标（有已确认关键注记时）+ 事件标签行内 chips（top 2 + `+N` 溢出计数）；hover 标题行浮层显示全量事件标签（标签 ×窗口内条数）与已确认关键注记明细（标题 + 确认日期）。
  2. 左侧候选栏条目（编排态下的 `ComposeSidebar.vue` 候选话题引导区）：条目下追加精简一行（top 1-2 事件标签 + ★ 计数）。
  3. 右栏 Inspector **零改动**（既有 spec 边界：不得出现关联事件清单）。

## 受影响状态

- loading：候选链加载中话题带本就不渲染，新增字段随链到达，无独立 loading 态。
- empty：话题无关键注记 → 不显示 ★；无事件标签 → 不显示 chips 行（整行省略，不显示占位符）。
- error：候选链失败沿用现有错误呈现，新增字段不引入新错误路径。
- success：正常渲染；事件标签溢出走 `+N` 计数；hover 浮层在键盘焦点时同样可达（focus-visible）。

## 复用组件与布局模式

- 布局沿用编排态三栏（workspace 既有模式，不改宽度与溢出策略）。
- chips 复用既有标签 chip 视觉 token（同 `ComposeSidebar` 现有 chip 样式系）；★ 徽标为新增纯装饰元素（aria-label 描述"已确认关键注记 N 条"）。
- hover 浮层复用画布既有悬停浮层模式（`LaneComposeCanvas.vue` 成员散点悬停浮层同款挂载方式），不新造全局 popover 组件。

### Fixture 说明

5 个候选话题（持久话题维度），窗口 2026-10-31 — 2026-11-13（14 天），共 48 条成员事件。

- 每个成员事件带自己的事件标签 `tags[]`（0~2 个）——「同事件关联」判定需要它（成员级字段口径见待拍板项）。
- **已确认关键注记挂在具体成员上**：`keyNotes[] = { title, date, member }`（`member` = 该话题内的成员下标）；该注记对应的那一天 = 它命中的日期，画布节点角标与左栏日期条目共用这个映射。
- `RELATIONS` 是原关系边（示意）：勾选一个节点后，与它有原关系的一跳节点 = 相关节点（沿用真实实现 `relatedNodeIds` 口径）。
- 散点位置为示意；画布几何抄 `LaneComposeCanvas.vue`（话题带在上 / 日期轴居中 / 散点池在下，容器真实像素 1:1）。★ 用 `mdi:star-check`（取自 `front/app/assets/iconify-subset.json` 本地子集内联，运行时零联网）。

### 新口径

| 视觉 | 含义 | 触发 | 参与计算？ |
| --- | --- | --- | --- |
| 实心 + 勾 | 已选 | 点节点 | 否（只是勾选态） |
| 更大 + 更深 | 相关节点（接近程度） | 与已选有原关系的一跳节点 | 否（沿用现有接近程度口径） |
| **虚线环**（accent，粗细克制） | **同事件关联**（自动） | 相关节点 ∩ 与已选携带同一事件标签 | 否 |
| **★ 角标** | **已确认关键注记**（人工主权） | 该成员被人工确认过关键注记 | 否 |

- 虚线环与 ★ 是两套语言：虚线环 = 自动事件关联（圆环、虚线、accent）；★ = 人工确认（实心小星、accent、贴在节点右上角）。
- 节点浮层：顶部是注记明细（★ + 注记标题 + 确认日期），下面是标题 / 日期 · 归属；虚线环节点追加一行「事件关联：标签名」。

### 红线自查

- **纯展示**：虚线环与 ★ 都不参与选择、推荐、质心与任何计算；点一个节点只会切勾选态并重算「相关 / 同事件关联」两套展示。
- **★ 与虚线环视觉语言可分**：★ = 实心小星（角标，10px）；虚线环 = 虚线圆环（r = 点半径 + 4.5，1.1px 虚线）。
- **图例删了就不留任何可点过滤**：原型内无图例 / 无标签筛选控件；节点只做勾选，无点击过滤。
- **右栏 Inspector 零改动**：实测 Inspector 内无 ★、无虚线环、无事件标签元素。
- **空态省略不占位**：无注记的成员不带任何标记；无注记的话题左栏不展开事件列表。

### 双视口验收（agent-browser 截图 + DOM 断言）

- 1440×900 与 1920×1080：`documentElement.scrollWidth === clientWidth`（横向溢出：无），三栏 300px / 1fr / 320px 不破版；375 窄屏按既有登记例外回落为「新建泳道需要宽屏或横屏」提示。

- 残留检查：图例 / 色点行 / 事件线 / 着色节点的 DOM 命中数均为 **0**。

### 剩余待拍板项

1. **虚线环的触发口径——「同事件关联」怎么认定**：原型取「与已选节点携带**同一事件标签**」。备选：① 同一标签 + 时间上连续（真事件线）；② 语义同族（需要后端给归并关系）；③ 后端直接给「事件关联」边（最准但要多一个字段）。
2. **★ 角标样式微调**：原型用 9px 实心星（mdi:star-check，accent 色）贴在节点右上角。备选：加浅色底衬 / 换成实心方章 / 更大或更小 / 不用图标改用文字 ★。
