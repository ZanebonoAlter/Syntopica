2026-10-30。用户认为“方向”不如最初点连接模型直观，希望一眼看全关联，明确授权继续调整。**取消方向列表/起点页，进入即完整点线工作面；看关系、人工选事件、最后命名。** 总览/矩阵已批准冻结，不重绘；仅调整独立原型，不是产品实现批准。上版[方向合同](ui-design-lane-compose-directions-history.md)/原型保留。

## User Journey

1. 打开新建泳道，直接看完整点线图。默认显示13个可选点、52个已有泳道只读点及两端在pool中的全部112条原关系；不先经过方向列表，不默认选成员。
2. 图上编号对应左侧真实事件。点节点或标题只聚焦，在右侧看完整标题、日期和关联；高亮所有邻接原边，其余原边维持正常可见，不靠压暗隐藏关系。
3. 勾选左侧事件，或点右侧“选入本次泳道”。没有算法连线也能选，可跨原candidate归属自主组合，不受管理启用资格/相似距离门禁。
4. 右轨核对成员，独立移除；选中仅改变成员标记，不生成手工边或伪造算法关系。
5. 选完最后起名，只作离线模拟创建；关闭命名保草稿，返回需确认丢弃。创建成功回完整点线主面，不回“选方向”。

## Information Architecture

生产布局复用 `AppPageShell(mode=workspace)`，直接三栏，**不再有contained起点阶段**：

- 左：可选事件清单，完整标题自然换行＋真实日期＋图中编号＋checkbox。13条全量保留，独立纵滚，不按推荐筛选。
- 中：主点线图，直接使用可用宽高适配全部65个点与112条原关系，无图内横/纵滚动才能看全的门槛。横轴14个真实报告日期；可选点按同日避让堆叠，非语义聚类；下方已有5条泳道的只读节点作参照。
- 右：当前事件完整标题/日期/原关系/明确选入或移除、已选成员、唯一“起名并创建”主动作。右轨独立滚动，底部创建常驻。
- 顶部两个轻视图开关：“已有泳道（只读）”（默认开）、“点选时突出关联”（默认开）；“看全图”清焦点并恢复全部只读参照，不清成员。
- 更多：历史候选、质心参考、合并、回填、原型说明。历史不默认出现，不冒充当前推荐。完整图已经前置，不再藏在弹窗入口。
- 命名/管理等弹窗md（560px，≤92vw）。<768px仅提示宽屏/横屏；本轮不增加产品手机编排路由。

## Reuse & Data

- 复用方向版同一只读1974中东14天快照，资料截至2026-10-29；不重新生成材料，不新增后台查询/AI算法，不以假案例凑关系。
- candidates池65个带向量节点：13个非active可编排、52个active只读；topics管理名单50话题/32candidate。
- timeline原始67分区/123关系；只有65个pool端点可用于本轮图，显示其间全部112边。**不把67/123说成已全部展示，不补造另外2个未入pool节点。** 收起只读时13点/4边，开关是明确视图操作，默认全开。
- 所有连线逐条复用原from_id/to_id/relation_type，不新算聚类、距离阈值、方向质量或整组推荐；同一对点的identity/similarity可同时存在并分弧绘制。线不代表因果，不把人工共同归属写成关系。
- 编号只为图/清单互认，不是新闻事实、推荐排名或新话题；已有泳道行标签保留完整原名DOM，CSS两行省略并给title，悬停/聚焦可读原全文，不用JS截字冒充新标题。
- 图与详情不截top6；右轨关联事件明细由原边逐项反查并按另一端去重，保留该端点所有原边类型。它是依据浏览，不是新推荐算法。
- 产品API边界继续camelCase＋字符串ID；离线raw JSON映射不授权组件散落snake_case转换。产品实现复用 `useInlineCompose` / 原topics与compose-candidates/timeline API，不把原型写成另一套生产API模型。

## Visual Design

沿既有报刊双主题：纸/墨/赭红、细栏线；没有方向卡片、评分、热度墙、营销hero、浮动气泡或新图标依赖。图是视觉主角，操作退在两侧。

- 可选点朱红空心；选中朱红实心；焦点独立外环；已有泳道点细灰空心。形状/填充与checkbox共同表达状态，不只靠颜色。
- 原identity实线、similarity虚线；全部原边始终正常可见；焦点时只突出邻接原边，不压暗其余关系，不筛点或边。
- 左侧标题完整自然换行，独立滚动；点后自动定位对应清单条目。右侧原事件全文标题/来源泳道名不硬截断。
- 1440：侧栏248/270px，中央用剩余空间；1920：290/310px，图按可用空间整体适配。不是把全站文字随画布等比缩小。

## Interaction & States

| 状态/动作 | 契约 |
| --- | --- |
| 进入 | 65点/112边/13可选，0预选；无方向列表、无推荐组、无先选起点步骤 |
| 点节点/左侧标题/已选标题 | 只查看焦点，成员不变；全部原边仍在，突出所有邻接边 |
| 勾选/选入/移除 | 只改本次成员及点的填充，不挪查看焦点、不压暗关系；不造边；重复加入Set去重；0成员仍留完整图，创建禁用 |
| 无边事件 | 图与清单都在；明确“暂无已有连线，仍可人工选入”，不造推荐填空 |
| active节点 | 只读查看完整原题名/归属；不出现选入按钮，底层add也拒绝；跨正式泳道移入仍未批准 |
| 看全图 | 清焦点＋恢复已有泳道显示，65/112；保留全部人工成员 |
| 关已有泳道 | 只收起52只读节点，留下13可选/4原边；不改任何数据或选择 |
| 关突出关联 | 不删点删边，不清焦点/成员；全边回正常可见 |
| 键盘节点 | Tab/Enter/Space查看，不偷偷选入；重绘保留节点/checkbox键盘焦点；Tab目标即显示自绘圆环，不画遮编号的方框 |
| Esc | 命名/其他弹层只关闭该层并保草稿；主面有成员/名称则请求返回确认；无草稿仅清当前焦点 |
| 创建 | 最后命名、max120、空白错误提示；合法值仅本地模拟，回全图并重置，不导航生产 |
| 历史管理 | 明确入口才开；server can_activate决定原启用资格；旧历史带入保留原adopt方式及新增预选数量披露，不影响主面自主选择 |
| 空/错/加载 | 本交付为内嵌固定真实快照，无网络加载/失败；0选择、无边、历史搜索空态明确。产品API加载/错误/真实失败回滚不是本轮通过项 |

## Constraints & Open Questions

1. 本轮退回用户明确偏好的**点连接模型**，不是再换一种“方向”包装；上轮>=2事件/跨>=2报告日/默认3组等展示提案均不进入当前主面，也未改过后台。
2. 人工建题仍active/manual主权；不因缺边/相似度/观察中候选管理门槛阻止人工选择。启用candidate是另一路径，不与人工新建混为一谈。
3. 人工初始向量取有效所选分区均值，不是首个；直接启用不会补算质心；默认最近30条滚动、不足2回退等事实未变。未检测/修复任何旧质心，不回填历史快照。
4. 不新增永久人工边，不解除跨active迁移确认边界，不自动转正/归档/删除候选。
5. **部署后影响＋需要操作**：只更新原型与合同。产品页面/后台算法/数据库完全未变，未部署；用户不需配置、清理、重生成或回填。旧候选/旧快照/旧质心原样保留，不发生数据降级迁移。
6. 审批仍pending，用户认可继续调整不等于已批准这份新图；总览与矩阵原批准范围不变。
