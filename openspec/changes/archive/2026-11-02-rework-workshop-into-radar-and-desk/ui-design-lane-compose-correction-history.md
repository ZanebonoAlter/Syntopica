2026-10-30。用户反馈引导版看不到关系，算法漏匹配时人工纠错被弱化，要求按讨论再调原型。**本轮把事件与真实关系放回主面，推荐只是高亮，不是准入门槛。** 不新增关系算法，不把两次原型迭代当实现批准。上版 [引导版合同](ui-design-lane-compose-guided-history.md) 与 `revision-2026-10-30-lane-compose-guided/` 原型保留。

## User Journey

1. 仍从系统候选或一条事件开始；真实近期候选空态不造方向。
2. 进入编排，主面始终可浏览本窗全部13条未归属事件，并直接看它们已有的真实连线；不再只能看到算法推荐。
3. 点标题只查看焦点/关联，勾选框才改变成员。**无连线、无系统推荐的事件同样可以直接选入。**
4. 系统当前关联仅高亮提示；关闭高亮不减少事件、关系或选择权限。
5. 用常驻开关显示52条已有泳道节点及其关系，作为只读参照；不暗中从正式泳道抢走成员。
6. 右轨核对本次成员、当前事件、少量关联提示；确认后最后起名，模拟创建。
7. 保存不要求成员之间已存在关系或距离达标。人工选入不伪造算法连线；后台正式创建后以人工归属落库，而非手写永久语义边。

## Information Architecture

**模式：workspace**。沿当前固定视口/内部滚动契约，不另起产品路由，不把编排做成普通760px reader。

- 起点态沿引导版：一句主引导，近期候选（有才显示）与最近5条事件，更早/历史按需。
- 编排态标题：“由你决定，哪些事属于同一条线”。一句话说明没有线也能选。
- **主面事件与关系**：日期倒序，每日双列可读节点，主面内部滚动；默认全部13可选节点，不按焦点/距离/推荐过滤。
- 默认绘制可见节点之间全部真实关系（样本4条），不是top6子图。身份与相似分别实/虚线，同一节点对两类边保留不互相覆盖。
- 主面常驻两个视图开关：显示已有泳道节点（只读）；高亮当前关联。显示已有归属后共65节点、112条两端均在材料池的原始边。
- **右轨** `clamp(285px,23vw,360px)`：本次成员清单（可移除）→ 当前焦点 → 非强制的系统关联提示；独立滚动。
- 唯一底部主动作“下一步：起名并创建”；技术指标收进“质心与聚类参考”，不再收起事件本身和主面关系。
- 更多保留系统候选、完整图、全量池、合并、历史回填、说明；这些不是人工选漏项的唯一入口。
- <768px仅宽屏提示；原型提示页不授权新增产品路由，产品仍沿现有入口toast/关闭宿主降级。

## Reuse & Data

### 质心事实（已追代码，不代表真库旧数据已经健康）

| 路径 | 真实逻辑/代码 |
| --- | --- |
| 自动候选创建 | `daily_report_assignment.go:assignAndUpdateTopics` 把首个section向量写Embedding；这不等于后续永远只用第一个 |
| 候选/正式话题质心刷新 | `daily_report_repository.go:SaveReport` 提交后对touched话题刷新，candidate也在其中；失败仅日志、保留旧值 |
| 平均范围 | `daily_report_topic_repository.go:ComputeTopicCentroid` 按所属section的报告日期倒序，取最近CentroidWindow条有向量分区（默认30条，不是30天）；有效>=2等权均值，否则回退topic.Embedding |
| 匹配锚点 | `daily_report_assignment.go:topicAnchorVec` 优先Centroid，缺失/不可解析才Embedding |
| 直接启用候选 | `daily_report_topic_repository.go:UpdateTopic` 只改状态/标题/时间，不补算质心；旧candidate缺centroid仍可能使用首义向量，不把启用当修复 |
| 人工创建 | `daily_report_manual_topic.go:CreateManualTopic` 使用全部有效已选分区向量平均，写新topic.Embedding，active/manual；当时未显式写Centroid，通过Embedding回退使用这个均值，之后随日报滚动刷新 |
| 采纳草稿 | `useInlineCompose.ts:adopt` 使用当前14天pool内该候选owned均值预选，并非读取后台滚动Centroid |

所以“平均”是**同一泳道所属的事件/分区向量**，不是全板块所有候选话题。不能仅凭本次代码检查宣称旧首义偏移问题已回填解决。本快照topics没有Centroid/Embedding字段，单个候选当前是否首义回退未知，原型只说明事实、不显示假的健康徽标。

### 当前数据与边界

同前两版原始只读JSON逐字节复制，不重新请求：65条带向量分区（13非active可选、52active参照）、67时间线分区、123原始关系、50话题、32个中断候选。材料截至10/29。可选13节点之间4条边；65节点之间112条原边；其余原边端点不在当前可编排池，不补造节点。

产品复用锚点：`BoardComposeOverlay.vue`、`useInlineCompose.ts`、`ComposeSidebar.vue`。不新算距离、不启用尚未接入的整组选中推荐。主图全量画已有边；右轨仍沿焦点去重/距离排序top6，不能限制主图材料。

生产实现须复用 `AppPageShell(workspace)`、`AppInput`、`AppButton`、`AppDialog(md/xl)`；本原型原生控件不是新组件体系。相关代码路径均相对 `backend-go/internal/topicgraph/` 或 `front/app/features/tags/`。

## Visual Design

沿报刊式纸/墨/细分隔线及双主题。纸 `#f4f0e7`、墨 `#282722`、朱红 `#963e2e`、次要字 `#6b665d`（对纸5.01:1）。不加仪表盘、质量分数墙或发光网络图。

- 标题自然换行的事件节点是主阅读单元，不靠hover辨认小圆点。
- 已选：朱红勾选框＋浅底/侧标；焦点：墨色外框；有关联的节点：灰绿边；三个含义不混用。
- 实线=同一话题记录、虚线=算法相似；箭头忠实原始from→to。人工本次选择仅标成员，不伪造关系。
- 节点与边在同一滚动宿主；重绘/窗口变化时测量卡片端点，线不盖标题与操作。日期顺序不因推荐变化重排。65节点密集参照时其他原边保留为淡背景，当前节点全量邻接边以实色、独立端口/走线突出；不因右轨top6截断主图强调。密集态按“点节点读其全部原始邻居”验收，不承诺112条边同时逐条可读；所有材料与原边仍可达，非焦点仅作背景。

## Interaction & States

| 操作 | 约定 |
| --- | --- |
| 任意未归属节点 | 可直接勾选，不检查已有连线或相似阈值；加入后聚焦 |
| 标题点击 | 仅查看/聚焦，不改变成员 |
| 无关联节点 | 仍留在主面，右轨明确可继续人工勾选 |
| 关闭高亮 | 只撤强调，不撤节点/连线/成员 |
| 主面关系 | 保留全部当前可见两端的原始边；不把相似与身份合成“因果” |
| 最后成员移除 | 留在编排，可继续检查事件，创建按钮禁用；不强制退出纠错工作面 |
| 显示已有归属 | 加52个只读节点，勾选禁用、可点标题/从关联定位；收起不丢已有草稿或留巨型空白 |
| 右轨建议 | 只是快捷加入入口，不是材料全集；active参照可定位到主图 |
| 候选采纳 | 名称预填并保留已有选择；如有新增预选要提示数量及可移除，无owned不编造成员；直接启用仍是另一动作 |
| 起名 | 最后md弹层；说明使用有效已选成员平均，无连线门槛；空白拦截、关闭保草稿 |
| 质心说明 | 明确候选平时算平均/不足回退/启用不重算/旧值可能仍缺，未检测不伪造修复结论 |
| 完整图 | 作为更多中的原关系参照保留；图内焦点独立，不改成员/主区焦点 |
| 返回起点 | 保草稿，有继续入口；返回板块确认丢弃；主面Esc也请求确认，不静默清空，弹层Esc只关当前层 |
| 模拟创建 | 本地提示并重置，不发真实API、不导航生产页面、不移动旧数据 |

## Constraints & Open Questions

1. **人工归到同一泳道**与**保持不同归属而手画永久语义边**是两种能力。现有manual创建无距离/连线门槛；现有路由无独立永久手工边接口，关系重建会删旧边重算，不能假造“手动画线已持久”。
2. 跨正式泳道移入仍保持只读边界：本轮让误分材料可看、关系可比，不静默解除禁选。若要移出旧归属，需另定人工确认/事务/历史快照边界，不在UI原型里假装已支持。
3. 候选启用现有宿主≥2天与后端HitCount/CanActivate门槛冲突仍保留待核对；不顺手改业务规则。近期候选真实空态不造数据。
4. **部署后影响＋操作**：本次只有设计原型，没有产品部署/配置/迁移/回填。旧数据完全不变；旧候选缺质心风险仍在，不会随看原型自动修复。用户无需清理或重生成；若要修旧质心须另行确认并验证，不自动执行写任务。
