2026-10-30。用户指出上一版“信息太多，没引导，没重点”，授权再调一版。采用渐进披露：**先选起点 → 串起事件 → 起名创建**。只调整页面与交互接线，不补推荐算法。上一版三栏合同保留于 [历史合同](ui-design-lane-compose-three-column-history.md)，原型目录 `revision-2026-10-30-lane-compose/` 不覆盖。总览与矩阵批准边界不变。

## User Journey

1. 打开先回答“从哪里开始”：有近期候选就展示现有顺序前3个方向；没有则如实说明，直接展示按时间倒序的最近5条可选事件。更早事件、历史候选按需打开。
2. 选一条事件进入编排：左边只有已选事件，右边只有当前节点可继续加入的关联。
3. 加入关联后切换焦点，推荐仍沿原始关系；点击已选标题只切焦点，移除用独立按钮。用户不会为了看关联误取消成员。
4. 关联不足时可“再选其他事件”，从原14天材料池加入；或直接下一步。
5. 点“下一步：起名并创建”才出现名称输入，候选采纳的名称仍预填。关闭命名层不丢草稿；合法名称可模拟创建，真实产品成功应回矩阵高亮。
6. “返回选事件”保留成员和名称，提供继续编排入口；“返回板块”确认丢弃，Esc沿原型取消模拟。原候选“直接启用”与“采纳后新建”仍分开。

## Information Architecture

**布局模式：workspace**。固定视口，主区使用可用宽度，局部内容滚动；不是固定760px阅读页，不新增产品路由。

### 起点态

- 报头：板块/新建泳道；深浅主题、更多；原型标记只用于离线说明。
- 左侧主引导：“先选一个方向”，一句操作提示；已有草稿时提供“继续编排”。
- 右侧为唯一选择面：近期候选（有才显示）→ 最近5条事件 → 更早事件 → 历史候选轻入口。
- 历史候选不默认展开32项，不显示无用的候选计数墙、技术质量或名称框。
- 最近5条仅时间顺序截取，不是新推荐排名；展开后可访问完整13条可选事件。

### 编排态

- 标题“串起这条线”，一句操作提示，已选数/跨天数。
- 主区双栏各 `minmax(0,1fr)`：左已选事件（按日倒序），右当前焦点可加入的原始关联。
- 已有正式泳道归属项收进折叠参照组，距离/type收进“查看关联依据”；不被冒充可加入项。
- 底部唯一主动作“下一步：起名并创建”。“查看关系与聚类参考”为轻次级入口。
- “再选其他事件”打开原材料池，不让全量事件常驻抢注意力。
- 窄屏<768px隐藏工作台，仅示宽屏/横屏提示；独立原型提示页不是新增产品路由，产品仍沿原有入口toast/关闭宿主降级。

## Reuse & Data

- 代码事实沿 `front/app/features/tags/components/console/BoardComposeOverlay.vue`、`composables/useInlineCompose.ts`、`components/ComposeSidebar.vue`：14天材料，原候选采纳/启用/人工保存分离，焦点relations去重后按距离取6条，active归属只读。
- **不启用底层宿主尚未接入的整组向量推荐**，不加新相似关系或阈值、不调用AI。
- 只在展示时从原top6排除已选、折叠已有归属；不会为凑推荐数量补取第7条或跨窗查找。
- 同一套上一版只读快照，另存新目录reference，不重新请求：65条带向量分区（其中13条未归属active、可编排）、67时间线分区、123关系、50话题、32中断候选、13非active节点，资料截至2026-10-29。
- 当前32候选均无本窗owned；所以默认近期候选为空，历史采纳只预填名称。不造“优质候选”、不拼接近期候选名单、不借其它板块数据。
- 历史搜索仅离线关键词过滤，不宣称语义搜索可用；生产embed-query等既有边界不退役。
- 产品实现须复用 `AppPageShell(mode=workspace)`、`AppButton`、`AppInput`、`AppDialog(md=560/xl=1040)` 等。原型原生控件不授权新组件体系。

## Visual Design

保留报刊式paper/ink/rule与双主题，不另起美术方向。浅色纸 `#f4f0e7`、墨 `#282722`、朱红 `#963e2e`、次要字 `#6b665d`（对纸5.01:1）；深色沿已批token。

- 起点态用大标题与清晰行列表形成单一入口，不三栏平铺。
- 编排态只保留“两组事件＋一个主动作”。选中集合由左栏承载，不再满屏勾选框和重复“已选”徽标。
- 当前焦点用墨色左线/浅朱红底；标题可自然换行，无横向位移。
- 所有说明限于当前动作所需；距离、离群数、关系图只在请求时出现。

## Interaction & States

| 操作/状态 | 行为与边界 |
| --- | --- |
| 初始 | 不代选；无近期候选就呈现真实空态并引导选事件 |
| 选事件起步 | 加入成员并聚焦，进入编排；同一集合去重 |
| 已选标题 | **仅聚焦，不增删成员**；这是待审UI接线调整，不是新推荐规则 |
| 移除 | 独立动作；移除焦点则换到剩余成员，最后一条移除后回起点 |
| 推荐加入 | 加入并将焦点切到该节点，与现有addRelated语义相同 |
| 无可加入关联 | 说明可换已选事件继续看、另选事件或起名，不造相关推荐 |
| active参照 | 默认折叠，只读，不提供加入；关系图可聚焦查看，不改成员 |
| 历史候选采纳 | 名称预填、沿既有owned+相似未归属追加上限20；无owned/无成员时留在起点提示，不误入空编排 |
| 原候选直接启用 | 保留独立入口/禁用原因；不与人工新建混淆，不执行真实写入 |
| 返回选事件 | 草稿保留，可继续编排，也可从原池再加材料 |
| 起名 | 延后到md弹层；上限120；空白名称拦截；关闭保留名称和成员 |
| 创建 | 离线仅模拟成功并重置；提示真实产品应回矩阵高亮，不跳生产页面 |
| 更多 | 保留历史候选、关系/聚类参考、合并、历史回填、原型说明 |
| 关系/聚类参考 | xl按需面，保留全量关联开关、图内只读聚焦、距离均值/离群；图内焦点独立，不改变成员或主区焦点，不常驻 |
| 返回板块/Esc | 确认丢弃/既有取消模拟，不写任何真实数据；弹层Esc只关闭当前层 |

## Constraints & Open Questions

1. 本次是“把能力按操作进程露出来”，不是做新业务功能。日期轴、完整材料、历史候选、合并/回填不删除，只退出默认主画面。
2. 候选≥2天的现有宿主条件与 `can_activate` 冲突仍待另议；原型复现禁用，不将它升级为批准业务规则。
3. 真实快照不存在近期可采纳/可启用候选的成功样本，未伪造验证通过。
4. 已选标题只聚焦、命名后置、关系图后置是本轮审阅对象；旧三栏批准不存在，用户授权制作不等于批准实现。
5. **部署后影响＋操作**：只产原型/设计记录，不改产品、不部署、不迁移数据；用户无需配置、重生成、回填或清理。旧数据缺本窗材料/无关系照实降级，现有生命周期、历史快照不改写。
