## 效果核对

- 触发原因：上版能通过自动化却把纠错路径藏入弹窗；必须证明算法遗漏时主面仍可操作。
- 方法：相同三份只读样本，不触真库；在主面找到无任何原边7347并勾选，与7409共同创建模拟。
- 量化：默认13节点4边；展开65节点112边；勾选无边节点成员1→2，原边仍4；无边节点仍无新增from/to；创建可用并成功模拟。
- 结论：UI人工成线不再依赖算法边。测试不评价两新闻事实关联，不伪造推荐，不修改关系生成算法。

## 白盒附加

- 节点分类：未归属可选 / active只读；有边 / 无边；选中 / 焦点 / 关联高亮三态独立。
- 边分类：identity实线 / similarity虚线；同对两种原边同时存在；全量可见端点过滤；主图不top6截断。
- SVG：path长度有效，实/虚样式不同，ResizeObserver后重绘；13→65→13不留巨型空白；主图内部滚动；密集参照非焦点透明度≤0.15，焦点保持实色且各自path不重复；requestAnimationFrame后等待状态再断言；坐标覆盖不挡checkbox。
- 质心说明：候选平时滚动平均、默认30条、不足2回退、直接启用不重算、快照未导出字段未知；人工创建全有效已选均值。仅文案/源码事实核查，不替代后端实际计算测试或旧数据量化。
- 非适用：真库质心回填/重算、写API失败回滚、永久人工边保存（原型不实现），活跃泳道跨归属移入（边界未批准）。
