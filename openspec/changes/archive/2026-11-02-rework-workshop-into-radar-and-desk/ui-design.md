## User Journey

1. **先看谁在变化**：总览比较 12 个板块的关注强度、近/前 3 日分区变化、逐泳道 14 日活跃小矩阵与最新日报。当前真实资料为 4 关注、8 常温、0 热点，不伪造“今天必须看”。常温可以展开完整横比，也可从紧凑索引直接进板块或已有日报。
2. **今天读什么**：右栏“今日该读”给出真实日报标题、日期、文章/事件元信息；“今天可能升温”独立呈现现有条件计算的信号，不把它变成新关注公式。点击日报承接既有阅读台，不在本轮重绘正文。
3. **看一条线如何走到今天**：进入板块，选择 7/14/30/近 1 年窗口与泳道；矩阵和日期演进带同步。点行切换态势；演进节点以点径表达当日线索合计（无最密三日辅助），当日线索在下方工作面就地下读（默认最近有内容日）；长态势可展开，待结算不抹掉时间线。
4. **钻取具体一天**：点日格或同日演进节点，在下方内联当日工作面看完全部主题桶和线索标题，单条展开真实摘要、相关文章按需；显示“桶峰值 / 当日合计 / 主题桶数”三种不同含义。不弹日期浏览模态、不强滚/抢焦点；同日日报/归档动作保留日期与返回上下文。
5. **继续追踪与战略判断**：休眠组可展开，关联追踪徽标与已有 watch 管理入口保留。右轨常驻本板块体检/来源/构成、待确认候选和追踪；全局治理及唯一新建板块主入口只在总览。回总览再继续矩阵，保留当前板块、泳道与窗口。

**本阶段部署影响与操作**：仅总览将按已批准原型改为报刊式横比版面；真实统计、后台业务和其他页面不顺带改变。无需用户配置、重生成、清理或回填；旧数据不迁移、不重算，缺字段保留缺失与日期提示，不补造数值。实现与相关验证通过后按项目习惯部署前端；本文更新时尚未部署。

### 权威数据与口径

- 总览单次 overview 字段为权威：`attention`、`today_sections`、`last3_sections/prev3_sections`、`lanes[].counts`、`report_*`、`anchor_date/data_delayed`。关注分档沿用 ≥50 热点、≥15 关注、其余常温；只算既有 3 日环比，不另造关注公式或风险 KPI。
- 迷你矩阵为**分区数**，不是线索；每条泳道按现有行内最大值分档。升温沿用当日分区≥3 且≥近3日均值×2。不同板块锚点分别标日期，刚果截至10/25，不全称“今天”。没有精确日报完成时刻，不写23:30。
- 日格为同泳道同日各主题桶线索 **max**，3/7→7；移除最右重复总数。主题桶既有 `thread_count` 可用时优先使用，缺省才用 events 长度＋folded_count；计数仍未知则显示未知，不拿桶数补数。有分区0线索仍可打开，无分区为空。
- **演进带保留现有日合计口径**：节点数字与节点大小（点径）为当日各主题桶线索之和（「最密集三天」已在 scope-cleanup 批准稿撤销）；界面明确写“当日线索合计（非桶峰值）”。日格与演进不是两个都叫“线索”的含混数字；日详情同时解释两者，不改后端聚合。
- 排序沿用窗口线索合计降序→分区数→topic ID；休眠仅窗口分区≤2的展示分组，不是话题状态。candidate 不自动转正、不推断激活资格；watch 徽标只表示关联，不冒充完整 watch 条目数。
- 12板块×4档只读响应分别导入；每档成员来自对应文件，不能从365天推断14天成员。timeline 倒序输入先按日期升序，轴终点取实际最新有分区日，不能拿数组末项当今天。影视/卫生没有活跃泳道也能打开 overview 已知日报。
- 生产总览用单次overview；矩阵A=所选source档，B365仅按需补A同ID历史（source365档池共用一次），上限/失败分层见implementation-matrix-stage.md §2.2。48份导出只是原型离线包，不是线上请求方案。
- 中东体检82、幽灵9和体检时刻10/26 21:39是 reference/current-matrix-2560.png 的实页留样，UI明确标留样；挂载标签来自 overview。其他板块体检、完整来源/构成/watch 明细未导出，不编造、不借用、不补0。

## Interaction Contract

- 总览点板块进入对应控制台，点泳道小矩阵进入该泳道；点日报承接对应日期的既有阅读台。常温默认紧凑索引仍有日报入口，可展开全字段比较。
- 矩阵点行只切选中泳道，下方演进同步；追踪徽标保留。选中休眠泳道自动展开休眠展示组；手动收起时回活动泳道。切换窗口保留有效选中，原泳道不在该档响应时按原排序回退，不造额外成员。
- 日期高亮、最新日期/实际今天分别表达。日格与演进节点共用同一当日工作面；所有桶与导出的事件标题在同一滚动面，不分子页、不叠诊断层。主题桶零线索可打开；无分区日不编事件。
- 原型使用原生 modal dialog 的 Esc、焦点约束和单层遮罩，关闭恢复触发点；重绘保存舞台与左右栏滚动。产品实施复用标准宿主，不照搬原型另造弹层。
- `snapshot=null` 显示“态势待结算·时间线照常”，不等于无事件；非空态势可展开全文。演进标签基于真实 section/event 标题，不添加军事/外交方向 token、不伪造人工 confirmed 关键事件。
- 工作面默认选可见区间内最后一个有内容日（今日无分区即落到最近内容日并如实标注日期，不把旧数据称今天）。点标题就地展开该条真实摘要，相关文章按需；无最密三日反向跳转辅助。
- **近1年 = 365列矩阵容器内横滚（已批准形态，取代更早的30日可动视口提案）**：全年名单、排序、休眠仍按所选档响应（观察窗 A 路线，拖选不换名单）；矩阵 365 列在舞台容器内横向滚动（页面不纵滚/不页面级横滚），演进 >31 日改趋势图 + 折叠逐日索引。不是把365偷换30或新增后端时间聚合。
- 哈希保留 `board/lane/days`，本地状态允许返回总览后继续当前板块/泳道/窗口；file://禁用存储也能使用。无运行时 fetch、业务写入、远端字体或图标。
- 超范围入口用同一覆盖面明确呈现既有承接目标和参数，不渲染第三页、不显示“保存成功”。追踪入口可看当前窗关联泳道，但完整管理数据未导出，不假装可启停。

**User Journey（8D）**

1. 打开 0 正式泳道的板块（真库样本：少数派 50413 / 卫生健康 246030）：不再看到一屏空网格 + 一条孤零零的「2」；看到的是**当日分区面板**：当天日报里出现、还没归到任何泳道的分区竖排列表，每条带线索数与当时状态。
2. 选一条分区 → 就地展开该分区的线索标题（点标题看**逐字**摘要）；不跳页、不弹层、不抢焦点。
3. 想看这条线索以前有没有出现过 → 分区下方**节点轴**（点径 = 当日线索峰值），点节点原子切到那一日并定位同一分区。
4. 想读当天完整日报 → 面板头部「打开当天日报」（站内路由）；想看该日归档文章 → 「看此日归档」。两者都保留返回恢复。

**Information Architecture（8D）**

```text
矩阵区：泳道 × 日期（纯跨日语义）
 ├ 头部：泳道 × 日期 ｜ ⓘ 口径（弹层）｜ 数据截止 ｜ 看所选日 ↓
 ├ 日期轴：● = 有日报；选中日 = 一条规则线
 ├ 正式泳道行 × N（格值 = 同日各主题桶线索峰值）
 └ ▸ 休眠泳道 · 0（本窗无 → 一行小字，不占等重框）
   （0 正式泳道时：本区退化为「报日 chip 条 + 一行说明」，不铺 14 列空网格）

当日分区面板（选中日；未归泳道的日报分区）
 ├ 头部：▾ 2026-10-24 · 当日分区（当天日报里出现、还没归到任何泳道） · N 条
 ├ 条目（竖排）：标题 · 线索数 · 当时状态词（展开：线索标题 → 逐字摘要 → 相关文章）
 ├ 跨日节点轴（同归属其它日；点径 = 线索峰值；— = 当天无记录，· = 不在导出范围）
 └ 动作：打开当天日报 ｜ 看此日归档
```

**Interaction Contract（8D）**：选日唯一入口不变（报日列头 / 正式日格 / 演进节点 → 同一 `selectedDate`）；选分区 = 就地展开（inline accordion），下方阅读槽同步；点跨日节点 = 原子切日 + 定位分区；返回恢复沿用既有六字段载体，**不新增 `date=` query**；全程只读零写。
