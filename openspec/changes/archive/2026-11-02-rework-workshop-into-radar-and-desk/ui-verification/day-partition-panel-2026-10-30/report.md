## 二、父线程实测的交互（agent-browser 实点）

| 操作 | 结果 |
| --- | --- |
| 点报日 chip `●10/13` | 选中日切到 2026-10-13，`#board=246030&days=14&date=2026-10-13` 同步更新，面板头变「▾ 2026-10-13 · 当日分区」 |
| 点分区条目 | 就地展开：分区原题 + 「N 条线索 · 当时待观察」+ 线索标题列表（各带「＋」展开摘要）+ 跨日节点轴；无弹层、无跳转 |
| 点跨日节点 `10/13` | 原子切日：面板头切到 2026-10-13，条目内容换成该日真实分区「佛山卫健局批评医生收礼与习近平强调卫生健康发展道路」，未借别日/相似标题 |
| 点「打开当天日报」/「看此日归档」 | 按钮在位且不带外链符号（站内路由语义） |
