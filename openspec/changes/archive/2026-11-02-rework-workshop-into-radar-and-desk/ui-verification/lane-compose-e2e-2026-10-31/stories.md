# 新建泳道编排 — 真机端到端故事（agent-browser）

> 目的：满足「前端交互 change 主链路至少一个 agent-browser 落点」与 UI 机械断言要求（`standard/shared/test-design.md` 问句③ UI 验收）。
> 运行环境：**真实后端 + 真实数据**（不是原型离线样本）。入口：静态托管 `http://localhost:5100`（部署方式见 `docs/reference/deployment.md` §本地裸跑静态托管）。
> 执行者：主线程（实现线程不跑浏览器，留给主线程统一跑，避免与 build 抢树莓派资源）。
> 断言方式：**机械断言为准不依赖视觉**——元素存在/可见、点击后到达状态断言、原生 checkbox 的 `checked`/`indeterminate` 属性、SVG 几何量测（不越界、比例 1.0）、计数文本。截图只作留档。

## 1. 主链路故事（S1–S7）

| # | 故事 | 步骤要点 | 机械断言 |
| --- | --- | --- | --- |
| E1 | 进入编排态 | 版块态势页 → 新建泳道 | 候选栏有候选泳道卡且**无默认勾选**（所有 group checkbox `checked=false` 且 `indeterminate=false`）；画布有非 active 点；已有 active 泳道点**未画**（数量为 0 或不可见）；右栏只有三段 + 两 tab |
| E2 | 候选链真实命中 | 读候选栏 | 每张候选卡显示原名、成员数、首末日期、**连接跨度天数**；至少存在一张跨度 ≥3 天的卡（若该版块窗口内无合格候选 → 空态文案，不算失败，记为空态留痕） |
| E3 | 整组带入 | 点一张候选卡的标题（未全选时） | 该组成员 checkbox 全变 `checked=true`；计数变为组内全部成员；图上对应点出现已选标记（实心＋✓）；**未选组的成员不被连带勾选**；推荐列表**不含**被自动勾选的项（未自动补相似） |
| E4 | 半选与取消整组 | 取消组内一个成员 → 再点「取消整组」 | 半选态：组框 `indeterminate=true`；取消整组后组内成员全部 `checked=false`，**组外人工补选仍在**（计数回到组外数）；自动预填名被清空（若未人工改名） |
| E5 | 人工名不被覆盖 | 手动改名 → 再选/取消组 | 名称输入框的值仍是人工写的 |
| E6 | 质心推荐随成员重算 | 记录推荐列表首位距离 → 加入一条推荐 → 再看 | 加入后该条从待选消失且出现在「已选事件」tab；推荐首位距离随新均值变化；推荐项**无**勾号（未自动选中） |
| E7 | 节点卡跟随与快捷选入 | 悬停点 → 点选该点 | 悬停出现浮层（含完整标题）；点选后浮层**钉住**且位置跟随节点（移动鼠标不消失）；卡内有「＋选入本次泳道」；点击后成员真加入、按钮翻成「移出」、图上出现 ✓ |
| E8 | 节点卡取消 | 点卡上 × → 或再点同一节点 | 卡片收起、右栏「当前事件的线索」回到空态、该点不再有已选标记（若它已被选入，其成员状态仍按真实选择） |
| E9 | 右栏两 tab 与已选取消 | 切到「已选事件」tab → 取消一条 | 该成员立即移出本次、计数同步、图上 ✓ 消失；切到「按标题找」tab 搜索一个标题 | 搜索结果**未被自动勾选**；右栏**不存在**「关联事件」「计算依据」「话题泳道参照」等区块 |
| E10 | 日期共窗与草稿确认 | 切近 7 天（有草稿时） | 先弹确认；确认后候选/图/推荐按 7 天窗口重算且成员清空；取消则控件与成员保持原样 |
| E11 | 日期非法 | 自选起止（起 > 止） | 报错提示、旧范围与草稿保留（成员数不变） |
| E12 | 已有泳道显式参照 | 打开「显示已有泳道（只读）」 | active 点出现且**只读**（节点卡内无选入按钮）；关闭后恢复；取消聚焦后开关状态**不被偷改** |
| E13 | 保存与缺名 | 名称留空 → 提交 | 报错、成员保留、未发创建请求；填名 → 提交 | 成功后回到版块态势页，新泳道出现在泳道列表（`source=manual`/`status=active`，后端核验） |
| E14 | 窄屏 | 375×667 与 390×844 | 显示宽屏提示；**无横向溢出**（`document.documentElement.scrollWidth <= innerWidth`） |

## 2. 几何断言（画布）

| # | 断言 | 量法 |
| --- | --- | --- |
| G1 | 1:1 比例 | `svg.getBoundingClientRect().width` 与 `svg.viewBox.baseVal.width` 差 < 1px |
| G2 | 无元素越出画布 | 所有 `svg text` / `rect`（横条）/ 点的 `getBBox()` 并集在画布内容框内（允许 1px 误差） |
| G3 | 点半径下限 | 普通点 `r >= 3`；已选点 `r` 严格大于所有推荐点 `r` |
| G4 | 话题带不压字 | 话题标题行两两不重叠（矩形相交判定） |
| G5 | 重排 | 改窗口宽度后 G1–G4 仍成立 |

## 4. 明确不在本轮真机范围

- 真实 `POST .../persistent-topics/manual` 的**事务回滚**路径（需构造失败）→ 人工豁免并留痕。
- 跨 active 泳道移入、永久人工关系边 → 功能本身不在本轮范围。
- 后台滚动 Centroid 的健康与回填 → 本轮质心是**前端草稿计算**，不落库，不受影响。
