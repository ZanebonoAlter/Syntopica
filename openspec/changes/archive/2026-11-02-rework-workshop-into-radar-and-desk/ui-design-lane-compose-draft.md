## User Journey

1. 默认近30天左3候选，组与每个成员都有复选框；图只画当前可选事件，不画active已有泳道及交叉边。
2. 勾候选1984或点标题，一次真勾上3个成员；左显3/3、图3个深色带✓节点、右成员3/可创建，不只浅底换色。
3. 每个成员可独立反勾；选部分时组框为半选，候选卡也要看得出半选（底色/左侧标记与未选不同），点击半选组补齐。再点全选标题/取消组框/点“取消整组”，撤销这组全部成员。
4. 取消组保留组外人工补选；“清空已选”撤全部选择。“取消本次”走原退出确认，不直接丢草稿。自动预填的名字跟它那一组走：该组被取消且名字未被手写改过时自动名一并清掉；手写名任何路径都不被吞（候选组、成员、历史名单“带入草稿”都不得覆盖）。
5. 待选推荐依真实成员质心距离显示：越接近，点越大、填色越深。它仍是待选，**只有✓/复选框才代表已选**；相近不自动勾选、不造边。
6. 如需上下文，手动勾“显示已有泳道（只读）”；取消聚焦或查看已有归属文字，不再偷偷打开117个旧点。图节点查看后右侧详情滚到可读位置。
7. 日期/后置命名/无边手动补选延续上版；有草稿改日期确认、取消恢复，一键3选仍允许10/29断档。
8. **右栏只做三件事**：顶部“当前事件的线索”（点开某个点时给标题/日期/归属，可选入或移出）；中部“可补充的事件”（前 5 条＋“再看 N 条”，一行行加，不自动选）；底部 tab 切「已选事件 / 按标题找」，已选每行一个真复选框，取消勾选即移出本次。画布里已经看得见的关联事件不再重复写；计算依据、话题泳道参照、其余推荐折叠全部去掉。
9. **画布是主角**：顶部一条“话题带”，每个候选话题占一行，横条跨它的首末成员并写上话题标题，成员用细垂线连回自己的话题；标题多了不铺满，只画 6 条并写明“另有 N 个候选话题在左侧候选栏”，不静默藏。
10. **想读全文随时可得**：鼠标悬停任一点，浮层给完整事件标题、日期、质心距离、原关系条数；**点一点就把这张卡钉在那个节点旁边**（它跟着选中的节点走，鼠标移开也不消失），卡里直接有「＋ 选入本次泳道 / 移出本次泳道」快捷键；**卡右上角有 ×，点它＝取消选中这个节点**（卡片收起、右栏线索同时清空），再点一次同一个节点也等于取消选中。右栏“当前事件的线索”只做叙述，不再重复放按钮。取消聚焦卡片收起。画布默认只画话题带（其余两档仅原型对比用）。

## Information Architecture

沿 `AppPageShell(mode=workspace)` 三栏，无新页面：

- 左：候选组框＋标题按钮、跨度/日期、成员独立框、`已选N/总N`与取消整组。输入不嵌套在按钮里；组/成员/标题互不重复触发。
- 中：标题随显示范围标“候选与待选事件关系”或“全部事件关系”。已有泳道开关默认关；“取消聚焦”只清焦点，不改变参照偏好或成员。顶部可切标题三档（话题/全部/编号），默认话题档。
- 右：自上而下三段——① 当前事件的线索（点开时才有，**只叙述**：标题/日期/归属/归档来源，不再放第二个选入按钮）② 可补充的事件（前 5 条＋展开）③ tab 区（已选事件 / 按标题找）。底部仍只有取消本次＋起名并创建。关联事件清单、计算依据折叠、话题泳道参照、“其余 N 个推荐”折叠全部移除；手动找事件入口从左栏底部搬进右栏 tab，不留两份。
- 画布节点卡：悬停出现、点选后钉在被选节点旁（跟随节点移动），内含标题/日期/距离/关系条数与「＋选入 / 移出」快捷动作；右栏不再重复该动作。
- 原生组框真实checked/indeterminate，成员真实checked；半选/已选数及图勾号从同一selected集合派生，不伪造视觉成功。
- 日期、手动补选、历史/合并/回填均保留（质心依据收成“可补充的事件”标题下的一行说明，细节在原型说明里）；md弹窗、两桌面/双主题、<768宽屏提示契约不变。

## Reuse & Data

复用上一版同一10/30真实90天快照，不新GET、不改JSON/向量/原边。基础30天pool仍155/267，其中active117，默认可见非active **38点/9条两端可见原边**；手动开启参照才回155/267。资格仍3个原candidate片段，1984三成员7345/7409/7514，日期27/28/30，跨度3天。

候选仍同ID原identity/similarity连通片段UTC日差≥3，非连续3天/非固定3节点；7/14/30/90候选1/2/3/19。点击整组的目标设置使用 `candidateSelection`，Set去重、明确true目标幂等；标题点击/组框是双向切换，不再用旧“重复点标题仍保3”断言。

成员均值与余弦、原阈值0.3、非active优先/active次级只读均不变。1984三选仍23非active/114active达阈；图默认不画active，不等于把它从计算池删掉。旧阈值较宽，依然不保证每条语义适合，仍需人工选。

`pointAppearance` 仅视觉映射：对待选推荐取截断到[0,1]的`1-distance/threshold`，映射填色深浅/半径；半径受列间距上限约束，防密集点重叠。它不是置信度百分比，不改资格/排序；普通点灰空心，已选单独深色＋✓，不以大点/深色猜选中。

历史管理可见/启用仍server can_activate，不为与素材候选同列表降低观察中门槛；归档来源标注与原非active可选资格保留，不自动激活。产品仍复用useInlineCompose与API边界camelCase/字符串ID；原型不是另一套生产API模型。

## Visual Design

沿报刊纸墨/赭红双主题。未选普通点灰细圈；待选相近点有序深浅/大小；已选实心带白✓，查看焦点另用墨环。**推荐点半径恒小于已选点半径**：大小只表达接近程度，选中只由实心＋✓表达，大点不得被读成已选。图例明确区分“已选”和“质心越近越大越深”（示意三档，非精确刻度）。

默认隐藏active后，可选点充分利用图高度，不把它们挤在上方一小带。所有当前可见端点原边保留，非焦点边不因选择被压暗。显式开启active才绘对应只读点/边；任何选择操作不改变点坐标或显示偏好。

左右独立滚动、标题自然换行、SVG圆形焦点不遮字；≤45天候选编号互认，90天两侧不编号而不删点。原生checkbox+✓提供非颜色冗余，避免“越近”被误当“已选”。

画布主视觉：话题带用细横条＋衬线标题，标题写在行内（带纸色描边光晕），与日期轴分层不压字；成员垂线淡到只作指向。全部档的每点标题用避让算法，挤不下就跳过而不叠字；编号档只留编号。画布宽度优先：两侧栏收窄（270/310），画布拿到剩余全部。

**画布按容器实际像素 1:1 画**：viewBox 宽度取画布内容区的真实宽度，窗口尺寸变化即重排重绘（不再拿开页那刻的旧宽度算），所以点不会被整体放大或缩到 87%。点的尺寸以像素为准：1440 下普通点约 12px 直径、待选推荐随距离最大约 15px、已选约 20px（1920 相应放大）。**任何元素都不许出画布**：标题避让带边界检查（放不下就少画），贴右侧的编号在越界时翻到点的左边，话题标题在无左侧空间时收进自己的横条并截断（悬停可见全文）。

## Interaction & States

| 操作/状态 | 行为 |
| --- | --- |
| 默认 | 组/成员0勾选，active开关关、38/9，保存/清空禁用 |
| 组框或标题 | 未全选→补齐组成员；全选→取消组。3成员示例真checked3/图✓3 |
| 部分成员 | 组框indeterminate、计数N/3、标题aria-pressed=mixed；成员可逐个调整 |
| 取消整组 | 该组所有成员撤销，不影响组外补选；组外6574实测保留 |
| 清空已选 | 全部成员/半选/图勾号清零，推荐回空；不删除历史/话题 |
| 名称 | 自动预填名跟它那一组走：该组被取消且名字未被手写改过时自动清；手写名保留，重选与历史名单“带入草稿”都不得覆盖 |
| 取消本次 | 有草稿先确认；继续编排保留选择，确认仅清本地草稿/回默认隐藏参照 |
| 聚焦 | 只改查看与原邻接强调；不勾选、不改成员质心、不自动开active；右详情可见 |
| 参照开关 | 仅用户明确开/关改变；取消聚焦保持用户偏好，active仍只读 |
| 查看active推荐 | 可读原题名/归属及“图中已隐藏”提示，不偷偷打开旧泳道图 |
| 推荐 | 加减重算，颜色/大小来自真实距离；必须明确加入才出现✓ |
| 日期 | 同窗候选/图/推荐；确认才清草稿，取消控件恢复；默认隐藏偏好不被重置为显示 |
| 无边/归档来源 | 手动可补，原来源如实标记；不伪造边、不自动恢复归档状态 |
| 创建 | 名称空白错误、关层保留；模拟成功保留日期，恢复新草稿的active默认隐藏 |
| 右栏 tab | 「已选事件」列出已选并带真复选框，取消勾选即移出本次；「按标题找」只在本窗范围内过滤标题，不自动勾选；两个 tab 切换不丢选择 |
| 右栏精简 | 页面不得再出现“查看关联事件/计算依据/已有泳道参照”；关联关系只在画布上表达 |
| 画布标题档 | 话题档给候选话题带与标题（≤6条，其余明说）；全部档给每点截断标题并自动避让；编号档无标题；切换只改呈现，不改选择/候选/质心 |
| 悬停 | 悬停出完整标题浮层（标题/日期/距离/关系条数）；移开即收；不产生选择副作用 |
| 节点卡 | 选中节点后卡片 SHALL 钉在该节点旁并跟随；卡内「＋选入/移出」SHALL 真实改本次成员并当场翻字；卡右上角 × 或再点同一节点 SHALL 取消选中（卡片收起、右栏线索清空）；取消聚焦才收起；右栏 SHALL NOT 再放重复按钮 |
| 已有泳道节点卡 | 只读：SHALL 不给选入按钮，只说明归属与需另行确认 |
| 画布尺寸 | 窗口变化后 SHALL 重排重绘并保持 1:1 像素；点 SHALL 足够大可读；任何标题/编号/横条 SHALL 不越出画布右边界 |

## Constraints & Open Questions

- 只改原型与需求制品；推荐算法/阈值、后台状态机、旧Embedding/Centroid与历史快照不动。跨active移入、永久手工边仍未开放。
- **素材边界（事实）**：90天样本 453 节点/790 两端可见边/19 候选，11 个归档来源分区**全在 10/01 之前**，因此默认 30 天窗看不到“来自已归档泳道”标注；该展示只在 90 天窗可验（已验）。30天默认窗为 155 节点（117 active 只读）/267 边/3 候选，默认不画 active 时显示 38 点 / 9 条两端可见原边。
- 本样本30天与90天支持窗同上版；正式产品仍须权威completed日期元数据，不在空首尾日报时用分区min/max猜窗。
- **画布标题默认档已拍板（2026-10-31 用户当面选）**：默认「话题带 + 散点悬停」——只有候选话题在画布上常显标题（顶部话题带，每话题一行，成员细线连回），散料点保持干净，读全文靠悬停浮层；原型内的「全部标题」「只留编号」两档仅供对比，不进产品要求。右栏 tab 拍板为两页：「已选事件」（带复选框可取消勾选）/「按标题找」，「可补充的事件」固定在 tab 上方那一段。
- **画布标题补充拍板（2026-11-01 用户补充建议，实现期落产品）**：默认档不变（无选中时散料点仍不显标题），但**一旦有选中成员**，与已选成员**有原关系**（1 跳）的**其它**节点 SHALL 在**节点下方**显示**标题缩略**（≤10 字带省略号）——只认原关系、不做传递闭包、已选成员自己不算、放不下宁缺勿叠。该补充属「新建泳道工作面」批准范围内，不扩批总览/矩阵；归档视图线不受影响。
- **部署影响＋操作**：仅本原型选择/视觉变化，产品页面未改、未部署；无用户配置/清理/迁移/重生成/归档/回填，旧数据原样，无新增数据降级。
- major审批仍pending；允许继续调整不等于本版批准，已批总览/矩阵不动，产品实现/归档门禁留后续。
