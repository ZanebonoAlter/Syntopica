2026-10-30。用户明确纠正：左侧应是候选话题泳道的一系列事件，点击一次可整组选中，例如3个节点；日期筛选须纳入；再按计算质心推荐相关事件，优先未入已有泳道。**最终门槛是连接跨越3天，不是连续3天。** 先前“近30天无连续3天候选”的统计已撤回，不是本版结论。

## User Journey

1. 进入workspace，默认近30天，左边是3条真实候选泳道，每条展开自己的事件系列，而非散装事件清单。
2. 点击“以色列选举”候选，一次带入10/27、10/28、10/30三个事件节点；中间缺10/29也满足，日期差3天。
3. 图中这3点成为已选实心；右侧按3份有效成员向量平均计算补充推荐，默认优先显示未入正式泳道的事件。**基础3成员和待选推荐不混在一起**，推荐不自动勾选。
4. 明确加入/移除后，按全部当前成员均值实时重算；点击原候选追加缺失基础成员、去重且保留已有人工补选。
5. 不符合候选跨度或没有算法连线的事件，仍可点图/手动按标题补选；不能把算法资格变成人工准入门禁。
6. 日期可用7/14/30/90天或自选起止。候选、成员、图、推荐共用一窗；有草稿改日期先确认清空，取消恢复原范围与控件。
7. 最后命名，空白拦截、关闭保草稿；仅本地模拟创建，不写入系统。

## Information Architecture

全程 `AppPageShell(mode=workspace)`，无中间方向页：

- 顶部：日期快捷select＋当前起止；选自定义才显示原生起止input及应用，初始30天，以最新完成日报为末日。原型90天样本边界8/02—10/30，不默默截断更久日期。
- 左栏：候选泳道列表，原标题→事件数/连接跨度/首末日期→全部成员原标题/日期。整个候选按钮一次带入，已带入浅底标记；无符合候选时真实空态。底部“手动找事件补选”另开md，不把散装清单夺回主位。
- 中栏：本窗全部pool点及两端可见原关系，已有active默认只读显示；不按推荐筛图。平均质心推荐只给优先组加虚环，不造新的事件间连线；active次级推荐不在图上批量加环。
- 右栏：当前查看（有才显示）/核对已选折叠/可补充推荐。非active优先组默认先5条、其余可展开；已有泳道推荐另折叠、仅可查看。唯一“起名并创建”主动作固定底部。
- 更多：保留历史候选管理/质心依据/合并/回填说明；历史资格沿can_activate，主候选连接跨度不是管理启用条件。
- 命名、日期丢弃确认、手动补选、历史管理均md；小于768px只提示宽屏/横屏。

## Reuse & Data

### 候选计算

`compose-logic.js:candidateChains(pool, links)` 按原candidate ID分组，仅用本窗原relations连接的连通片段。不同ID不能靠相似边并成一个原候选；同ID断开的片段不混选。片段至少2节点，`(max报告日期-min报告日期)/86400000 >= 3`；**不是连续3天、累计3次、至少3节点或把首尾覆盖日期数当跨度**。同一ID若有多个合格片段可分列，名称不改写；不添加语义关系。

### 整组带入与均值推荐

`adoptLane` 只追加片段全部实际成员，Set去重，不截20条，不调用旧adopt相似补选。空名称可预填原名，不吞原人工选择；查看焦点不随带入移动。

`centroidRecommendations` 对当前有效成员取均值，对本窗未选节点算余弦距离，沿原matchThreshold=0.3筛选并按距离/ID排序。优先组包含所有未入active的事件，包括其他candidate成员，不仅是persistentTopicId为空者；active只在次级参照。加减成员重算，无成员/无有效均值不假造推荐。原后台滚动Centroid、首义Embedding和本次草稿均值是不同来源，不混用。

**距离达阈值不等于语义已经确认**：本次真实30天选1984后有23个非active、114个active达阈；原阈值较宽，未声称质量已改善或全部适合这条线，必须人工核对，不擅自修改后台阈值/模型。

## Visual Design

沿报刊双主题，不换美术风格。左300/右300px（1920为320/330），中央尽量给图；左候选事件全原标题自然换行，不靠截图裁标题。成员实心、候选空心、推荐虚环、查看墨环分离；不因选中压暗全图。图保留全部点/边，候选成员在不超过45天窗口常显编号，与左侧一一对应；90天左右两边都不显示编号，保留完整标题查看。较大窗口稀疏日期刻度、缩点，避免重叠；这不是筛数据。

推荐仅平铺标题/日期/实际距离和加入按钮，无质量分/热度墙；次级active默认收起。成员可展开核对，不与待选推荐混色。SVG原生outline禁用，以鼠标/键盘自绘圆环显示focus；编号纸色描边，避免线穿字。

## Interaction & States

| 状态/动作 | 行为 |
| --- | --- |
| 默认30天 | 3候选、155点/267边、0已选，无默认相似补选 |
| 点击1984 | 精确3已选，名称可预填；候选浅底，查看焦点不变 |
| 推荐 | 按成员均值实时算；优先非active、次级active只读；未展开项仍可查看，图中不删点/边 |
| 加入/移除 | 仅明确项改变成员、重算均值与推荐；原候选基础成员被移除可再点击补回 |
| 手动补漏 | 当前范围按标题搜全部非active，不受跨度/相似/连线门禁；无边7347实测可加入，不造边 |
| 改日期无草稿 | 应用后统一重算候选/图/推荐 |
| 改日期有草稿 | 先确认清空名称与成员；取消、关闭、Esc恢复旧范围、控件及全部成员 |
| 非法日期 | 空值、开始晚于结束、超样本支持窗，报错且不改实际范围/草稿 |
| 空候选窗 | 单日等无跨3天候选真实空态，图与手动补选仍可用 |
| 看全图/只读开关 | 保留草稿；只改变参照显示，不过滤候选资格/推荐来源；active仍不可选 |
| 归档来源 | 可选项明确标原归档泳道，不伪装无归属、不自动激活旧话题 |
| 查看节点 | 只改focus，不替代成员质心、不变选择；原关系按邻接高亮但其余正常可见 |
| 创建/取消 | 最后命名max120/空白拦截；关命名保草稿；模拟成功保留当前日期并重置选择 |
| 加载/错误 | 固定内嵌只读样本无网络加载；未把产品API失败/空库/异步重试写成通过 |

## Constraints & Open Questions

1. **连接跨度是用户最终修正**；之前连续出现3天的提案/统计均撤回，不入本版需求。管理累计HitCount资格/生命周期/历史快照不受本界面规则改变。
2. 人工直接active/manual，不因少节点/缺关系/距离偏大被挡。已有active跨泳道移入、永久人工边仍未批准；推荐active只读，不借推荐开放迁移。
3. 历史adopt组合行为只保留在明确管理入口，不混入新主面；原型mean/distance已委托同一centroidOf/cosineFor口径。左候选包含观察中素材片段，历史列表按既有累计命中可见门槛，不强行同一可见集、不降低FilterVisibleTopics门槛。候选直接启用不重算质心；旧质心健康/回填未检测，不宣称修复。
4. **部署后影响＋操作**：本次只有原型/需求制品变化，产品/后台/数据原样，未部署。无需配置、清理、迁移、重生成、归档或回填；旧数据没有新增降级路径，旧候选/快照不动。
5. 审批仍pending，不能把用户继续调整视为本版UI批准；总览/矩阵冻结不变。更久历史、自选原生接口、真实保存/失败回滚、语义准确性须正式实现/另议验证。
