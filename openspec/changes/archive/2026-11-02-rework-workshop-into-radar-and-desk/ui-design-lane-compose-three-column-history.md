## User Journey

1. 从当前板块“新建泳道”进入全屏编排；系统候选作为指导，不自动创建。
2. 左侧查看候选，采纳时沿用既有预填名称＋追加预选；也可直接从中间按天事件找切入点。
3. 勾选成员；事件标题复用现有画布点击动作（聚焦＋切换勾选），右侧显示该节点的真实关联。
4. 从关联项加入成员，焦点随新加入节点移动，继续检查；允许撤销勾选。
5. 填名称后保存，真实产品成功应返回矩阵高亮新泳道；原型仅本地模拟，不写数据。
6. “直接启用”是将原候选转 active，不是按草稿新建；不与保存合并。返回/Esc 丢弃草稿，真实已有泳道不变。

## Information Architecture

- 布局选择 **workspace**，全屏编辑工作台，固定视口＋分区内部滚动；不是 760px reader，也不是 contained 居中表单。
- 报头：当前板块 / 新建泳道、原型待审标记、双主题、说明。
- 工具条：返回、页面名、泳道名称、更多、保存泳道。
- 左栏 `clamp(240px,20vw,340px)`：系统候选、搜索、近期/中断分组；独立滚动。
- 主栏 `minmax(0,1fr)`：标题可读的日期事件清单为主，已有节点关系图在下方作为参照；清单与关系图各自滚动。“只看已选”仅过滤当前成员的视图，不改集合、不新增取数或推荐。
- 右栏 `clamp(270px,23vw,380px)`：当前焦点、最近关联节点；独立滚动。
- 底栏：已选数量、覆盖天数（仅选中日期去重的界面摘要）、折叠聚类参考、快照截止日期。
- “更多”保留合并与历史回填入口、真实作用说明，不在本轮重设计或执行这些流程。
- <768px 不渲染残缺工作台，仅显示需要宽屏/横屏。768–1100px 栏宽收紧，不扩大功能范围。此独立文件的窄屏页只用于展示禁用原因，不是新增产品路由；产品仍沿用现有入口提示/宿主关闭的降级行为，不授权新建窄屏编排页。

采集日2026-10-30，材料日期2026-10-16—10-29；65个可编排节点中13个非 active。话题接口本次返回的候选均没有当前可编排成员；可编排池又有未在这50话题名单内的 candidate 引用。**原型不补造名单、不把相近标题视为同一话题、不修改样本来凑成功候选**。直接展示中断候选与本窗0条。这一数据落差是原接口事实，后续如需补全数据须另议。

## Visual Design

沿总览批准方向的 paper/ink/rule：纸色 `#f4f0e7`、墨色 `#282722`、朱红 `#963e2e`、灰绿参照色；次要文字收深至 `#6b665d`，对纸色对比度5.01:1；深色沿原型既有 token 对应值。中文报刊式衬线标题＋无衬线操作信息，系统本地字体，无网络字体/图标。

三栏由细分隔线与栏目顶线界定，不堆卡片；选中用朱红复选框和浅朱红底标记，焦点用墨色侧线区分；行内边距固定，切换焦点不横移。日期与距离是次要信息。技术指标默认折叠，标题自然换行，不用不可读省略号隐藏事件正文。

## Interaction & States

- 初始没有选中、没有焦点，右栏解释如何开始；不擅自代选。
- **本轮待审接线**：列表复选框只 toggle（现有逻辑）；事件标题复用 `onNodeClick` 的聚焦＋toggle。这样无需找圆点也能触发已有推荐；不是“整组推荐”或新算法。已选标题再点会取消勾选，保留既有画布语义，不偷偷引入“只聚焦”模式。需用户看片后确认该操作是否易懂。
- 未归属：可选、可加入；active：关系图可聚焦查看、不可勾选，右侧只能参考。
- 关联取最多6项；无关联如实空态；缺失距离不补值。
- 候选采纳只改草稿，不持久写；候选无本窗成员时明确提示“仅预填名称”。
- 搜索离线只演示现有标题关键词过滤；不调用 embed-query，不假装支持语义检索或把主列表重排。当前宿主本就未消费 rankedPool/recommendations。
- 名称空白/无成员阻止保存，保留草稿。保存成功仅弹模拟确认并重置本地演示，不导航真实页面；明确说明产品应返回矩阵。
- 返回先确认丢弃；Esc 无弹窗时清空草稿，仅本地模拟。此原型不对现有产品取消策略作数据写入改变。
- 合并/回填只保留入口与作用说明；不执行，不宣称主流程已实现/验证。
- 模拟加载/接口失败未伪造为实样；生产仍须保留独立读取失败、重试、已有草稿等既有错误边界。原型是离线输入，不将离线成功冒充接口成功。

## Constraints & Open Questions

1. 不追加“整组选中推荐”、摘要阅读、新搜索算法、跨泳道移入或生命周期自动化。
2. **启用条件待核对**：宿主覆盖为 `consecutive_hits>=2`，底层原本使用 `can_activate`，本次实样两者冲突（0天但 can_activate=true）。原型复现宿主禁用态，绝不把“2天”提升为批准业务规则；以人工主权和配置门槛为权威。
3. 未在话题名单中的近期 candidate、名单中的历史 candidate 无本窗成员，是资料与当前接口的可见边界；不在原型内修后端。
4. 不将新原型批准扩展到其他未审页面，不覆盖总览/矩阵冻结文件。
5. **部署后影响＋操作**：本次只产原型和设计记录，产品行为/数据/部署不变，无用户配置、重生成、回填或清理操作。旧数据不迁移；无本窗材料降级为0条/仅预填，无关系显示空态。
