## User Journey

**入口**（不新增页面、不新增导航项）：

1. `设置 → 订阅源`（`/settings?section=feeds`）——既有 master/detail split 工作台。**主任务**：一眼看出哪些订阅源在灌杂音，并在同一屏内处置（调最大文章数 / 关打标 / 退订，动作全部沿用既有控件）。
2. `/tags` 板块页 → 「板块内容」tab（默认 tab）底部新增「来源构成」面板。**主任务**：反向看「这个板块是靠哪些源撑起来的」，识别只偶尔命中该板块、整体杂音高的源。tab 栏不变、不新增导航面。

**次任务**：切换统计窗口（7/30/90 天）对比短期与长期表现；按入板块率/篇数排序定位极端源；在板块页追溯某条供血源的来源。

**用户视角的一句话**：以前只能靠翻列表感受「今天又灌了 800 篇没用的」，现在每个源旁边直接写着「入板块 26%（437 / 1662）」。

## Information Architecture

**设置 → 订阅源（在既有结构内新增信息层，不改分区）**

```
设置工作台（既有：左侧 section 导航 + 右侧 section 内容）
└─ 订阅源 section（既有：工具栏 4 入口 + split 工作台）
   ├─ 左栏 master（既有：搜索框 + 分类分组列表）
   │  ├─ [新增] 列表工具栏：窗口分段控件 / 排序 select / 「只看低命中」筛选 chip
   │  ├─ 列表项（既有：图标 + 标题 + meta 行）
   │  │  └─ [扩展] meta 行加「7 天内 N 篇 · 入板块 M」；行右端 [新增] 入板块率 pill
   │  └─ [既有] 分类折叠
   └─ 右栏 detail（既有：头部 / 状态条 / 设置表单）
      └─ [新增] 「来源质量」块 —— 位置：状态条之后、设置表单之前（先给观测结论，再往下调参数）
         ├─ 头部：标题 + 口径说明 + 窗口分段控件（与左栏工具栏共享同一状态）
         ├─ 堆叠条 + 图例：入板块 / 有标签无板块 / 打标排队中 / 已处理无标签
         ├─ 入板块率数值（大字）+ 分子分母
         └─ 命中板块分布 chips（Top 6 + 「其他 N 个板块」）
```

**`/tags` 板块页（「板块内容」tab 内追加面板，tab 栏与既有板块详情结构不变）**

```
/tags（既有：板块列表侧栏 + 主区 tab 栏，tab 栏保持既有五项不变）
└─ 主区 tab 栏：[既有] 板块内容 / 话题总览 / 日报 / 文章 / 数据增强
   └─ 「板块内容」tab（默认 tab）
      ├─ [既有] 板块构成面板（BoardCompositionPanel）
      └─ [新增]「来源构成」面板 —— 位于板块构成之后、tab 内容最末
         ├─ 汇总行：窗口分段控件 · 本板块 N 篇 · 来源 M 个 · 最大来源（占比）
         ├─ 排序控件：按篇数 ↓（默认）/ 按该源入板块率 ↑
         ├─ 来源表：订阅源 | 本板块篇数 | 占本板块（条+%）| 该源入板块率 | 该源窗口内总量
         └─ 口径脚注（含「同一文章命中多板块时在各板块各计一次」与「只读」说明）
```

信息层级原则：**列表给出可比较的单一数字（率），详情给三分解与分布，板块页给反向构成**——不引入新的仪表盘页面，不新增导航，不新增 tab。

## Interaction Contract

| 操作 | 类型 | 行为与反馈 |
| --- | --- | --- |
| 切换窗口 7/30/90 天 | 主 | 列表工具栏与详情块共用同一窗口状态（任一处切换两处同步）；切换后立即按新窗口重取聚合数据；请求中该区显示骨架占位，不阻塞列表与详情其它内容 |
| 排序（默认 / 入板块率 ↑ / 篇数 ↓ / 杂音量 ↓） | 主 | 纯前端排序，**在分类分组内排序**（保留既有分类 IA）；无样本源的排位规则见 State Matrix |
| 「只看低命中」筛选 chip | 主 | 筛选条件：窗口内 ≥ 5 篇 **且** 入板块率 < 30%；`tagging_enabled=false` 的源（打标关闭，率恒为 0）**不参与**该筛选；筛选后空分类自动隐藏；再次点击取消 |
| 点击列表项 | 主 | 既有行为不变（选中并展示详情） |
| 选中板块，「板块内容」tab 底部来源面板加载 | 主 | 面板随板块选中并行拉取（选中即取，不另设入口）；切换板块时按新 board_id 重取，旧请求结果不覆盖新板块 |
| 板块页排序切换 | 次 | 纯前端重排来源表 |
| 详情内调最大文章数 / 关打标 / 退订 | 危险（既有） | 本 change 不改这些控件的行为与确认流程；**本 change 不新增任何动作按钮** |
| 统计加载失败 | — | 该区块内显示「统计加载失败」+「重试」；不弹全局错误、不影响列表与设置项可编辑 |

**只读边界（硬约定）**：本 change 的所有新增交互均为只读展示/筛选/排序，不新增写端点、不新增破坏性动作。

## State Matrix

| 区块 | loading | empty | error | success |
| --- | --- | --- | --- | --- |
| 列表 pill（入板块率） | pill 位置显示 `—` 灰底（不抖动布局，宽度与数字态一致） | 窗口内 0 篇 → pill「无新文」；窗口内 < 5 篇 → pill「样本少」（不猜百分比） | 聚合整体失败 → pill 显示 `—` 并保留既有 meta 信息 | 高 ≥60% / 中 30–60% / 低 <30% 三档配色 pill；`tagging_enabled=false` → 灰 pill「打标关闭」 |
| 列表 meta 行 | 沿用既有「刷新中…」等状态 | 无文章时显示「N 天内 0 篇」 | 同左（不显示不可信数字） | 「7 天内 1662 篇 · 入板块 437」 |
| 排序/筛选控件 | 立即生效（数据未到时不显示筛选结果，显示占位） | 筛选后无结果 → 列表区提示「没有符合筛选条件的订阅源」+ 复位入口 | 控件保持可用 | 控件选中态持久于当前页面生命周期 |
| 详情「来源质量」块 | 骨架条 + 图例置灰 | 窗口内 0 篇 → 「近 7 天没有新文章」；< 5 篇 → 「样本不足（N 篇）」；`tagging_enabled=false` → 明示「该源已关闭打标，不参与板块归属」，不显示 0% 率 | 「统计加载失败（原因）」+「重试」；块内失败不影响下方设置表单 | 堆叠条 + 图例 + 率 + 板块 chips |
| 板块页「来源构成」面板 | 随「板块内容」tab 渲染，加载中显示骨架占位（不阻塞上方板块构成） | 该板块窗口内 0 篇 → 「近 7 天没有文章归入本板块」+ 切窗口提示 | 「统计加载失败」+「重试」，不影响板块构成与其它 tab | 汇总行 + 来源表（按当前排序） |
| 板块页来源表 | 同上 | 来源表为空但文章数 > 0（理论不可能）→ 显示「来源解析不可用」，并保留总数 | 同上 | 表行 + 占比条 + pill |

**错误恢复路径**：所有统计失败都可在原区块内点「重试」重取；重试走同一端点、不改变窗口与排序状态。

## Layout Contract

| 面 | layout mode | 说明 |
| --- | --- | --- |
| 设置 → 订阅源 | `split`（既有，不新建模式） | master 栏 `width: 320px; min-width: 280px`（既有值）；detail 栏 `flex: 1; min-width: 0`。新增的工具栏在 master 栏内单行 flex + `flex-wrap: wrap`（窄栏自动换行，不横向溢出）；列表项 pill 固定不收缩（`flex: none`），标题区 `min-width: 0` + ellipsis |
| `/tags` → 板块内容 tab 内来源面板 | `workspace`（既有，不新建模式） | 板块侧栏 210px 定宽（既有值）；主区 `flex: 1; min-width: 0`，面板位于「板块内容」tab 内容末尾（板块构成之后），表格 `width: 100%` 按百分比列宽（34/12/22/16/16），比例条固定 110px。主区宽度变化时面板随宽度伸缩，不出现横向滚动条 |

- **目标视口**：桌面 `1440×900` 与 `1920×1080`（major 双视口验收）；1920 下 split 两栏等比例拉宽、表格列按百分比拉伸，不出现空洞居中或超宽正文列。
- **窄屏**：产品既有设置页在窄屏切换为纵向堆叠（既有媒体查询），本 change 沿用；`< 1024px` 时列表工具栏换行、来源表隐藏「该源窗口内总量」列（次要列），不新增窄屏专用布局。
- **无 dialog**：本 change 不新增弹窗，`AppDialog` 尺寸档不涉及。
