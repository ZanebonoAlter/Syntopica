## SQL（BEFORE：旧 `articles.*` 投影）

```sql
EXPLAIN (ANALYZE, BUFFERS, FORMAT TEXT)
SELECT articles.*, feeds.category_id AS category_id,
       (SELECT COUNT(*) FROM article_topic_tags att_cnt WHERE att_cnt.article_id = articles.id) AS tag_count
FROM articles
LEFT JOIN feeds ON articles.feed_id = feeds.id
WHERE articles.archived = false
ORDER BY articles.pub_date DESC
LIMIT 20;
```
