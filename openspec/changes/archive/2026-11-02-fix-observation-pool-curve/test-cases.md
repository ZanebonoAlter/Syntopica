# 用例设计：fix-observation-pool-curve

> 依据 `docs/reference/standard/shared/test-design.md`（测什么/变体/层选择/验收措辞）。
> 主链路 = 用户打开版块态势矩阵页 → 顶部时间视窗折线缩略图应显示完整历史趋势（不必先拖动）。

## 1. 主链路（故事锚点）

| 编号 | 故事 | 验收判据（可机械断言） | 层 | 落点 |
| --- | --- | --- | --- | --- |
| M-1 | 打开矩阵页，顶部折线缩略图直接有历史曲线 | A 档响应到位后自动发出 365 池请求；池窗口非空；档窗外历史日可解析为 `content/pool`；观察范围与 `sourceDays` 不变 | composable | `useBoardConsole.observation.test.ts` |
| M-2 | 池已就绪时，曲线 series 含档窗外历史日的真实值 | `poolSeries` 在历史日 = 真实线索合计（6）；档窗内当日仍按 A 口径；池已取到的断档日 = 已知 0 | composable（派生） | `useConsoleSelection.test.ts` |
| M-3 | 池没取到时，曲线不伪造历史 | 历史日 = `null`（不补 0、不桥接），而不是画一条假曲线 | composable（派生） | `useConsoleSelection.test.ts` |
| M-4 | 池请求失败时，用户看得到并能自己重试 | 首屏（未拖动）即出现池提示条（含错误文案）+「重试历史池」按钮；A 侧名单/矩阵照常可读；重试成功提示消失 | 组件（DOM） | `BoardConsoleShellSelection.test.ts` |

## 2. 变体走查（分支表）

| 变体 | 触发条件 | 期望 | 落点 |
| --- | --- | --- | --- |
| V-1 档位=365 | 用户点「近 1 年」 | 档/池共用一次请求，**不**额外发第二次 365 | `useBoardConsole.observation.test.ts`（OX-8） |
| V-2 档位切换 | 14 → 7 → 30 → 365 → 14 | 请求序列 `[14,365,7,30]`（365 预取与 365 档共用缓存），回切命中缓存不发请求 | 同上（CA-2） |
| V-3 深链恢复 | `?days=30&start=&end=` | 恢复范围与档位；请求序列 `[30,365]`（档 + 池预取） | 同上（OX-9） |
| V-4 池失败 | 365 请求返回失败 | A 可读、名单/排序不动、历史日 `unavailable`（`?` 不补 0）、范围不动、可单独重试 | 同上（OX-12）+ `BoardConsoleShellSelection.test.ts` |
| V-5 池刷新失败 | 池已就绪后刷新失败 | 保留旧池并标陈旧；A 侧不动 | 同上（R29） |
| V-6 切板块 | 切到另一板块 | 池随板块复位并重取新板块自己的池（旧板历史日不得留在窗口里）；A 通道 epoch 隔离（旧板迟到响应不回填） | 同上（切板块 / OX-10） |
| V-7 A 首败 | A 档首取失败 | 不因池成功而冒充 A 成功；A 错误态 + 重试 | 同上（OX-13） |
| V-8 无锚点 | 板块无日报/无数据 | 锚点未知 → 不发池请求（无曲线可画，不做无用读） | `useBoardConsole.observation.test.ts`（0 泳道/无日报用例） |
| V-9 拖出档窗 | 用户把选区拖到档窗之外 | 池已在首屏取到，拖动不产生额外池请求；历史格显示真实内容 | `useBoardConsole.observation.test.ts`（OX-1/OX-2） |

## 3. 效果核对（与用户报障对账）

- 报障原话：「折线图缩略图第一次加载永远只展示当前时间 14 天的，必须拖动下才 load 历史的曲线趋势」。
- 修复前：首屏池未取到 → 曲线只有档窗那几天（M-1/M-2 的断言在修复前为红）。
- 修复后：首屏即取池 → 曲线含历史（M-1/M-2 绿）；用户**不需要**再拖动（V-9）。
- 副作用对账：多一次 `days=365` 读请求（每板块会话内缓存复用，切档/切板块不重复发）。

## 4. 继承与调整

| 既有用例 | 调整 | 理由 |
| --- | --- | --- |
| OX-9（深链恢复） | 请求序列断言 `[30]` → `[30,365]` | 池预取新增一次 365 请求 |
| CA-2（四档缓存） | 请求序列断言 `[14,7,30,365]` → `[14,365,7,30]` | 同上；365 预取先于档切换到达，365 档命中缓存不再发 |
| OX-10（epoch 隔离） | 断言「切板块后池窗口为 null」→ 断言「池窗口不含旧板块历史日」 | 新板块会正常预取自己的池，旧板块迟到响应仍不回填（epoch 语义不变） |
| OX-12（A 成功 B 失败） | 构造方式由「拖出档窗时池失败」改为「池首取即失败」 | 池首屏即取，失败发生在首取；场景语义（A 可读/历史未取到/可重试）不变 |
| 切板块（池复位） | 断言「池窗口为 null」→ 断言「池窗口只含新板块历史日」 | 同 OX-10 |
| `useBoardConsole.test.ts` / `BoardConsoleShellNavigation.test.ts` / `BoardConsoleShellStates.test.ts` | 「最后一次调用 = 档响应」→ 「按 days 过滤的 A 档调用」 | 预取后末位是 365 池请求，原断言的语义（档响应）不变、只是不再用「最后一次」表达 |
