# Proposal: 关键事件视角「引线树标签 + 日聚焦卡片」

<!-- complexity: complex -->
<!-- ui-impact: major -->
<!-- constraint-domains: semantic-board, daily-report -->

## Why

版块态势页的「关键事件」视角（`?view=events`）是一张多泳道横向时间轴：行 = 持久化话题，列 = 日期，事件是骑在生命线上的圆点 + 向右摊开的标题药丸。用户原话：「不能一眼就看清楚那一天发生了什么关键事件」。三处硬伤：

1. **看不出标签是哪一天的**。标签宽 150–330px，日期列只有 64–165px；4 条标签阶梯状往右下摊开，离自己的圆点 46–200px，唯一线索是标签左缘的小圆点比轴线上的圆点偏右 12px。用户实看原型后的结论：「最大的问题是看不懂这是哪一天的事件」。位置本身编码不了日期。
2. **「那一天」读不到内容**。同日多条事件按 12px 步长挤在 18px 圆点上互相压盖；行头只给「N 事件 · 最近 MM/DD」；事件详情只在底部一份跨话题平铺的列表里，看不出「这条泳道那天发生了什么」。
3. **「那一天」不可直达**。没有日期选择器，选中日只能靠逐个点圆点推进。

本 change 把两件事做成一等读数：**每条标签用引线连回它的圆点**（静态可读是哪一天），**选中日在每条泳道内就地展开卡片列**（一屏读完那天发生了什么）。

## What Changes

1. **引线树标签**：标签交替挂在生命线**上下两带**，每条标签一根折线引线连回自己的圆点；同一天多条从并排主干**树形分叉**到上下堆叠的标签；行高随标签动态撑开（4 层时 178px）。收起判据不变：总层数 > 4 的行才收成「圆点 + ★N」。
2. **日聚焦卡片列**：选中日（`selectedDate`，与矩阵共用）在**所有**有该日事件的泳道行内就地展开卡片列——日期打头、标题（完整不截断）、所属话题、摘要（可展开）、关联文章（可展开，走既有文章预览）。≤ 4 张全部展开、不设行高封顶；靠右放不下时向左展开。
3. **移除下方「当日关键事件」阅读区**（**BREAKING，仅本视图**）：其全部能力由泳道内卡片承接；`KeyEventDayPanel.vue` 及其测试删除。连带：休眠泳道在选中日有事件时自动展开当天有事件的行。
4. **视图自带「所属日期」下拉 + 「MM/DD · n 条」**（视图头一行；写入同一个 `selectedDate`，不新建状态）。
5. **同日圆点步长 24px**（原 12px，18px 圆点互相压盖 6px）。
6. **行头补「当日 k 条」**。
7. **悬停强调**（pinned）：悬停标签 / 圆点时加重其引线、圆点与轴头日期，不改变选中态。

## Non-Goals

- **不改数据层**：端点 `GET /semantic-boards/:id/key-events?days=N`、表结构、注记三态、快照字段一律不动（标题 / 摘要 / 文章 ID / 话题快照已全在前端手上）。
- **不改横向时间轴模型**：行 = 话题、列 = 日期、列宽 `max(64px, 可用宽/可见日数)`、舞台内横滚、行头 sticky、选中日滚入视口——全部保留。
- **不改列宽公式、不改 4 层收起判据、不改与矩阵共用的观察窗控件。**
- **不把日期写进标签本体**作为契约要求（用户选择用引线解决；原型里的开关仅供对比）。
- **不做每泳道独立大事记轴、不做泳道内竖排卡片**：会丢掉跨话题横向对时。
- **不提供注记写入口**；**不呈现 `suggested` / `dismissed`**；**不渲染候选话题行**。
- **不新增弹窗 / 抽屉**；文章预览仍走既有 `ArticlePreviewModal`。

## Capabilities

### Modified Capabilities

- `workshop-board-console` — 关键事件视图：标签改为上下两带 + 引线树；新增日聚焦卡片列与视图自带日期下拉；移除下方阅读区（原「点节点后下方阅读区展示该日全部确认事件」「下方事件卡可展开关联文章」「事件名称改由选中日阅读区呈现」三条行为改为由泳道内卡片承接）；休眠泳道选中日自动展开；同日圆点步长 24px。既有只读性 / 共用跨度 / 列宽 / 不截断等 MUST 全部保持。

## Impact

- **前端（改）**：`console/KeyEventTimelineView.vue`（行内渲染：上下两带 + 引线 + 卡片列；移除底部阅读区挂载与「查看下方」按钮文案）、`console/keyEventLayout.ts`（标签分层由单侧贪心改为双侧代价分配 + 引线几何；同日步长）、`console/KeyEventLabel.vue`（标签去旧圆点、改双带定位，引线在视图的 SVG 层）。
- **前端（新增）**：`console/KeyEventDayCard.vue`（单张日聚焦卡片）。
- **前端（删除）**：`console/KeyEventDayPanel.vue` + `KeyEventDayPanel.test.ts`（仅关键事件视图使用；能力去向见 design 的旧能力去向表）。
- **前端数据层**：`useBoardKeyEvents.ts` / `boardKeyEvents.ts` / `normalizers/boardKeyEvents.ts` **零改动**。
- **后端**：零改动。
- **文档**：`docs/reference/flow/semantic-board.md` 约束 37 措辞「（时间轴与当日阅读区）都不呈现」改为「（时间轴与日聚焦卡片）都不呈现」——**语义不变，只换承载面名称**；归档时同步 `openspec/specs/workshop-board-console/spec.md`。
- **红线**：不新增 / 不放宽 / 不删除任何 MUST。
