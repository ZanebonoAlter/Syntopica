## User Journey

### 页面入口

| 入口 | 路径 / 位置 | 触发 | 承载 |
|---|---|---|---|
| E1 · 雷达行「⋯」 | L0 `/tags`，`BoardRadarStory.vue` 行尾 | 点行尾「⋯」（**不触发整行跳转**） | 版块轻编辑（名称/描述/排序/受保护）+ 归档 |
| E2 · 矩阵行「⋯」 | L1 `/tags/:boardId`，`ObservationMatrixLaneRow.vue` 行头 | 点行头「⋯」 | **「编辑泳道」→ 进画布（修正模式）**；另有归档（轻量弹窗） |
| E3 · 泳道管理 | L1 顶栏「板块管理」→「泳道管理」 | 顶栏 dropdown | 泳道列表：进画布 / 归档 / 候选激活 |
| E4 · 编排入口 | L1 顶栏「新建泳道」 | 顶栏 | **既有新建泳道画布（不改）**——修正画布与它共用同一骨架，修正模式是其「已有泳道」变体 |

### 用户主任务

**T1（主）· 在画布上修正一条泳道。**
泳道串味 / 定义不准 → E2 或 E3 进画布（修正模式）→ 中央画布看到这条泳道的**现有节点铺开** → 左栏「本泳道成员」就是**当前成员**（勾选态可见，**看得见当时选了哪个节点**）→ 取消某节点的勾选即**移除**它（该内容不再归属任何泳道）→ 或在左栏「首义范围」手动勾选一组节点重设首义 → **逐条即时落库**（移除 / 加回 / 首义各自一次请求，**无全局保存动作**）。

**T2（主）· 移除一条误入内容。**
画布上该节点取消勾选 → 该内容**不再归属任何泳道**（内容不删，仍可再参与候选）→ 泳道内容与热度即时更新，质心次日重算。

**T3（次）· 手动重设首义范围。**
画布左栏「首义范围」勾选一组节点（**看得见当时选了哪个节点**）→「用选中的 N 个节点定首义」→ 服务端按这组节点的 embedding 取均值写入首义 → 次日重心按新首义重算。

**T4（次）· 改个名字 / 归档。**
改名的**主路径**是修正工作面标题就地编辑（见 T3 同段）；泳道管理列表另有 `sm` 档重命名弹窗作为次要路径。归档走 E2 / E3 的 `sm` 档弹窗 + 二次确认。

### 关键用户认知

1. **派生值次日生效**：重设首义 / 剔除节点改的是**事实**，重心、真空标记、泳道快照是算法每天重算的草稿。界面必须明写「次日日报生效」。
2. **移除不是删除**：内容从本泳道移除后**不再归属任何泳道**，但**内容仍在**，以后仍可再参与候选。
3. **首义 = 一组被选中的节点**：首义不是一句描述，而是「哪些节点定义这条泳道」——服务端按这组节点的 embedding 取均值（mean pooling）。画布上**看得见当时选了哪些节点**。
4. **首义范围与成员集合是两回事**：成员 = 这条泳道当前归属的全部内容；首义范围 = 其中被指定为「定义面」的一个子集。移除节点 = 移出成员集合（该内容不再归属任何泳道）。

### 区块划分（左栏承载全部操作，画布只做可视化）

| 位置 | 内容 | 对应动作 | 生效时机 |
|---|---|---|---|
| **左栏「本泳道成员」** | 当前成员清单（勾选态 = 归属本泳道） | 取消勾选 = **移除**（不再归属任何泳道）；勾选 = 加入 | 归属**立即生效**；重心/快照**次日** |
| **左栏「已移出（本次）」** | 本次会话中移除的节点（可加回） | 点「加回来」= 加回本泳道 | 同上 |
| **左栏「关联推荐」** | 按成员质心推荐的关联节点 | 点「加入」= 加入本泳道 | 同上 |
| **左栏「已移出（本次）」** | 本次会话中被移除的节点 | 点「加回来」= 加回本泳道 | 同上 |
| **左栏「首义范围」** | 手动选定的节点子集（= 这条泳道「是什么」的来源）+ 当前首义来源展示 | 设为新首义 | **次日**（重心重算） |
| 中央画布 | 节点散点 + 话题带 + 节点卡 | 只做**可视化与查看**（点节点 = 选中查看），不改归属 | — |
| 顶栏 | 返回 / 泳道名（可就地编辑）/ 日期窗口 | **无全局保存动作**——移除 / 加回 / 首义各自即时落库 | — |

**信息全部在左栏**（用户从左往右读）；中央画布只负责把节点位置与关系画出来，**不做写操作**；**没有右栏**。

**画布是唯一主战场**；弹窗只承载改名 / 归档这类单字段轻量操作，不再试图在弹窗里解决「看清选了哪些节点 + 重设定义面」两件事。

## Interaction Contract

### 主操作（全部在画布内）

| 操作 | 交互 | 反馈 |
|---|---|---|
| **移除节点** | 在左栏「本泳道成员」取消某节点勾选（或节点卡上的「移出本泳道」）→ **直接移除**，SHALL NOT 弹出目标话题选择器 | 该节点从列表移出；toast「已移除，该内容不再归属任何泳道，仍可再参与候选」；画布**不关闭** |
| **加入节点** | 左栏勾选候选成员，或点左栏「关联推荐」的「加入」 | 该节点进入本泳道；toast「已加入」 |
| **加回节点** | 左栏「已移出（本次）」分组点「加回来」 | 该节点从「已移出」移出、回到「本泳道成员」；toast「已加回」 |
| **改名泳道** | 修正工作面**标题处的泳道名就地编辑**（点文字 → 输入框，Enter 提交 / Esc 取消 / 失焦取消），复用既有画布的名称输入区 | 提交即落库（逐条即时生效），toast「泳道名已更新」（不动派生值） |
| **设定首义范围** | 在左栏「首义范围」勾选一组节点（**限本泳道节点 + 当前首义集**；跨话题节点服务端 4xx 拒绝）→「用选中的 N 个节点定首义」；服务端按这组节点的 embedding 取均值（mean pooling）写入首义 | 确认条（**仅覆盖已有首义时**出现；首次设定直接提交）：「当前首义来源：自动（首条命中内容）。重设后判定基准会改变，继续？」→ 成功后 toast「首义已更新，次日日报生效」 |
| **逐条即时落库** | 移除 / 加回 / 首义重设**各自一次请求**，写操作**立即落库**；顶栏**无「保存」按钮、无全局保存动作** | 每次操作各自 toast（移除 / 加回 / 首义各一条）；失败时行内错误并保留本轮未提交的改动 |

> **首义范围边界**（与 delta spec `lane-correction-surface` / `lane-manual-correction` 同口径）：所选节点 SHALL 属**本话题**、同 board、embedding 存在且维度一致；任一条不满足 SHALL **整体拒绝该次写入**（服务端 4xx），SHALL NOT 静默跳过、SHALL NOT 写成部分落库。

### 画布交互约束（复用既有编排画布纪律）

- **查看与选入分离**（既有纪律）：画布上点节点 = 选中查看；勾选/取消勾选 = 选入/移出。取消勾选是**破坏性**动作，SHALL 与「取消选中」在视觉与交互上明确区分。
- **画布不做写操作**：移除 / 加入 / 设定首义 SHALL 全部从左栏发起；画布只负责展示与聚焦。
- **拖拽平移不误伤点选**（既有纪律）。
- 节点卡跟随选中节点并可快捷选入（既有纪律）。

### 轻量弹窗操作（`sm` 420 / `md` 560 档）

| 操作 | 弹窗 | 内容 | 反馈 |
|---|---|---|---|
| 重命名泳道（次要路径） | `sm` | 名称输入 | toast「泳道名已更新」（立即生效） |
| 归档泳道 | `sm` | 状态切归档 + 二次确认（`useConfirm`） | toast「已归档，该泳道不再吸附新内容」（可逆） |
| 编辑版块 | `md` | 名称 / 描述 / 排序 / 受保护 | toast「版块已更新」 |
| 归档版块 | `md` | 二次确认 + 手打版块名（沿用 `useBoardCRUD.ts:130` 惯例）；`protected=true` 时禁用并说明原因 | toast「已归档」 |

**改名的��路径是就地编辑**——就在修正工作面的标题处改（见上节），**SHALL NOT 弹对话框**；泳道管理列表另保留一个 `sm` 档重命名弹窗作为次要路径。归档是破坏性操作，SHALL 留在弹窗里做二次确认。

### 界面文字纪律

**产品界面 SHALL NOT 承载解说性长句。** 具体地，以下内容 SHALL NOT 出现在产品界面：

| 不得出现 | 例子 | 由什么承担 |
|---|---|---|
| 操作口径的并列解释 | 「点节点 = 选中查看（细圈）｜勾选 = 选入本泳道（实心 + 勾）｜取消勾选 = 移除」 | 交互自身的视觉（破坏性动作的样式差异、勾选态的图形区分、tooltip） |
| 派生值机制的科普 | 「重心 = α·首义 + (1-α)·滚动均值」「归属移除立即生效，重心 / 真空标记 / 泳道快照是算法每天重算的草稿」 | 只保留**结论型徽标**（「立即生效」「次日日报」），机制不进界面 |
| 画布图例的长句 | 「大小 / 深浅 = 接近程度（不是置信度）」 | 压缩为极简符号图例（≤8 字/项）或省略 |
| 节点卡里的教学语 | 「画布只做展示。要移除 / 加入 / 设定首义，请在左栏勾选。」 | 按钮本身的命名与位置 |

产品界面 SHALL 只保留三类文字：**动作标签**（按钮/菜单项）、**状态结论**（徽标、空态、错误）、**必要的确认/反馈**（toast、二次确认文案）。

所有解说性内容 SHALL 只出现在**评审外壳**（原型的评审说明区），SHALL NOT 进入产品界面。

### 危险操作

| 操作 | 二次确认 | 说明 |
|---|---|---|
| 移除节点 | 无二次确认弹窗；就地即时执行，toast 文案明示「该内容不再归属任何泳道，仍可再参与候选」 | 内容不删，只是解除归属 |
| 覆盖已有首义 | 画布内确认条 | 首义是定义面，覆盖影响该泳道全部未来归属 |
| 归档版块 | `AppConfirmDialog` + 手打版块名 | 软删（`status=disabled` + 清 embedding），可逆 |

### 明确不做

- **不做「立即重算重心」按钮**——改事实，派生值让算法每天自己刷。
- **不做「把内容彻底删除」**——移除 = 解除归属，内容仍在。
- **不做「选归处」**——移除就是不再归属任何泳道，不需要指定换到哪条泳道。
- **不做「拖拽重排泳道」**——行序由 `lane_heat` 决定。
- **不在弹窗里做修正**——弹窗只管单字段。

## State Matrix

### 画布（主战场）

| 状态 | 表现 | 恢复路径 |
|---|---|---|
| loading | 画布骨架（左栏列表灰条 + 中央空画布），不闪空态 | 自动；失败转 error |
| empty · 泳道无成员 | 左栏「这条泳道还没有成员」；同栏「首义范围」仍可见但无可选节点 | 先加入成员，或调整画布日期窗口 |
| empty · 画布无节点可展示 | 中央「该日期范围内没有可展示的事件」+ 提示调整窗口 | 调窗口 |
| error · 加载失败 | 画布顶部行内错误 + 「重试」；**不**呈现业务空态 | 重试 |
| error · 单条操作失败 | 画布底部行内错误，**保留本轮未提交的改动**（该条不落库） | 重试（同目标幂等） |
| success · 首义重设 | toast「首义已更新，次日日报生效」 | — |
| success · 移除 | toast「已移除，该内容不再归属任何泳道，仍可再参与候选」；节点从列表移出并进入「已移出（本次）」 | — |
| success · 加回 | toast「已加回」；节点从「已移出（本次）」回到「本泳道成员」 | — |
| 长内容 · 节点标题 | 节点标题两行截断 + `title` 全名；成员项名超长省略 | — |
| 长内容 · 左栏超高 | 左栏**整体纵向滚动**（三块堆叠总高超屏时）；块内长清单独立滚动，该块的操作按钮 SHALL 保持可见、SHALL NOT 被裁到视口外 | 滚左栏 |

### 轻量弹窗

| 状态 | 表现 |
|---|---|
| loading | 字段骨架 |
| error | 行内错误 + 保留输入 |
| success | toast |

## Prototype

`ui-prototype/index.html` —— 静态可丢弃原型，自包含单文件（内联 CSS + 少量 vanilla JS 做状态切换与画布绘制），**不连真实 API、不改产品代码**。

**打开方式**：浏览器直接打开 `openspec/changes/lane-manual-correction-loop/ui-prototype/index.html`。

**fixture 数据**（全部虚构，不含真实库数据）：
- 版块：`AI 前沿`、`新能源`
- 泳道：`Claude Code 工具链`（成员 4 条，跨 2 天）、`中东局势`（成员 6 条）
- 关联推荐候选：`长任务下的自动压缩与截断策略`、`多代理并行的日程与回放`
- 画布节点：8 个散点 + 1 条话题带

**与真实接口的解耦说明**：所有数据是写死的 JS 常量；交互只模拟「进画布 → 取消勾选移除 → 勾选首义节点 → 标题就地改名 → 提交 → toast」，**不发起任何网络请求**，也不依赖 `front/` 下任何代码。

**原型要展示的关键状态**：
1. **画布默认态**（修正模式）——**两栏**：左栏「本泳道成员 + 关联推荐 + 首义范围」/ 中央画布（**无右栏、无「当天其它话题」**）
2. **移除节点 + 已移出（本次）分组**（取消勾选 → 直接移除，**不弹任何选择器**；已移出分组里每条带「加回来」）
3. **首义范围勾选 + 覆盖确认条**
4. **雷达行「⋯」菜单 + 版块轻编辑弹窗**（`md` 档）
5. 画布 error 态（加载失败行内错误 + 重试，**不**呈现业务空态）
6. **标题就地改名**（点标题泳道名 → 输入框，Enter 保存 / Esc 取消 / 失焦取消，**不弹任何对话框**）

### 原型评审外壳 vs 产品界面

原型顶栏的 harness 区（状态标签页 + 状态模拟 + 契约锚点说明）是**评审外壳**，不属于产品界面。产品界面 SHALL 只保留动作标签 / 状态结论 / 必要反馈三类文字（见「界面文字纪律」）。

### 已记录的原型修正（2026-11-13）

**v1（弹窗主方案）已废弃**：用户评审指出「主场景应该是画布，剔除的也是，不是在一个弹窗中妄图解决所有问题」。信息架构与主流程变更，v1 原型与 v1 八节契约一并作废，`ui-approval` 重置为 `pending`（本就是 pending）。

**v2 追加修正**：首义**不是**写一句话、也**不复用**一句话追踪机制，而是「手动选择首义的话题节点范围」——首义 = 用户勾选的一组节点的 embedding 均值。v2 原型据此把右栏「一句话定义」区改为「首义范围（手动选节点）」。

v1 原型另有一处布局缺陷（归属内容块的 flex 基准高度取自列表内容高度，撑爆容器后触发收缩把列表压成 0 高），修正手法（`flex-basis: 0` + 最小高度保底）在 v2 复用时不再需要——v2 主战场是画布，无此结构。

**v3 追加修正**：三栏改两栏——原右栏（已选 / 关联推荐 / 首义范围）信息更全且与左栏「本泳道成员」重复，用户评审指出「左右重复了……可以全量移动到左侧，因为用户从左开始看的」。v3 起页面内不存在右栏。

**v4 追加修正**：「移除」不再选归处——用户评审「移除直接就是不归属任何泳道，不需要选择其他泳道改挂」；同时新增「已移出（本次）」分组与「加回来」（用户评审「已移出的本次应该也能再加回来」）。

**v5 追加修正**：两处——
1. **泳道名就地编辑**：用户评审「编辑泳道名称这个找个地方补上」。既有编排画布的**命名弹窗**（`AppDialog size="md"`）里已有「泳道名称」输入控件，修正模式沿用同一 `AppInput` 形态，在**标题处点文字即改**，**不弹对话框**；泳道管理列表另保留「重命名」弹窗（`sm` 档）作为次要路径。
2. **产品界面零解说**：用户评审「原型说明性文字太多了」。v5 删掉工具条口径说明、画布长图例、页脚长句、节点卡教学语；生效信息只以结论型徽标表达；解说内容全部挪到评审外壳。
