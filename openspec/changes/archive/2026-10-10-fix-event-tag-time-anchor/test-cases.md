# Test Cases: fix-event-tag-time-anchor

故事锚点：一篇发布于 D 日的文章触发新建 event 标签，其 description 时间锚与 D 日语境一致；存量病态标签可被扫描列出、人工圈选后重生成，且不影响健康标签。

复杂度声明：simple（prompt 文本替换 + 一次性 CLI；无算法/状态机/解析协议类新增——年份提取为单函数正则，附带白盒用例）。

## 变体走查（五组固定清单）

- **输入**：description 无年份 → 扫描不命中（有测试）；多年份取最早（"2020年至2023年间索贿" → 锚 2020，有测试）；全角数字年份 → 正则仅匹配半角 `20\d{2} 年`，全角属已知不覆盖边界（中文新闻 description 惯用半角，记录不处理）；description 为空串/纯空白 → 不命中（category 过滤前置）。
- **前置**：无候选（扫描返回空清单，正常退出码 0，有测试）；单候选；`--ids` 含重复 ID（去重后处理，有测试）；`--ids` 含非候选 ID（拒绝并报错，不触碰任何行，有测试）；`--ids` 含不存在 ID（报错提示）。
- **时间窗口**：desc 锚定年与创建年差 0 → 不命中（有测试）；差 1 → 命中（有测试）；跨年边界（12 月创建、desc 锚当年 1 月）→ 差 0 不命中（按年差计算，记录口径）；desc 锚未来年份 → 不命中（min 为负同样按"早于≥1"判定不成立）。
- **幂等**：重复执行扫描 → 修复后标签不再命中（有测试：重生成 mock 后复扫）；LLM 失败重试 → 沿用 generateTagDescription 既有 3 次重试，失败记日志跳过、不中断批处理（有测试：mock 失败路径）；并发 → 一次性 CLI 单线程顺序执行，不适用，划除。
- **可用性（UI 必检前三）**：本 change 无 UI 改动，误输入反馈/空态/错误态划除（CLI 参数错误有报错提示，见前置组）。

## 效果核对（④：效果依赖 LLM 行为 → 真库量化核对）

- **触发原因**：prompt 约束是否真实压住先验知识时间锚。
- **方法**：apply 后真库跑扫描 dry-run，量化候选数变化（修复前 176 → 修复后圈选部分清零）；抽样新生成 description ≥5 条人工核验时间锚。
- **量化结果**（2026-10-09 执行）：全量扫描（不限 60 天窗口）候选 321 个；人工圈选研究确认病态 4 个（183730 伊朗袭击以色列 / 197750 伊朗停止向船只装载原油 / 194440 英国男子遭暴力抢劫 / 200389 路某某再审改判无罪）→ `--apply --ids` 4/4 重生成成功；复扫候选 321 → 317，4 个修复标签全部不再命中。抽样 4 条新 description 全部销定"文章报道当期"（183730 显式带首挂文章日期 2026 年 9 月 28 日），无 Context 外历史年份。备份 CSV：/tmp/event-tag-anchor-backup-apply.csv。
- **结论**：时间锚纪律 prompt 双管（约束句 + 中性示例）在重生成路径实测有效；新建路径的后续行为由日报线索时间锚正确性持续观察（后续数日日报自然验证）。

## 展示字段盘点（⑤）

description 是用户可见字段（标签详情页/日报线索素材）。来源语义已在 delta spec `tagging-domain` 两条新 Requirement 中落锚（时间锚纪律 + 存量可修复性），无隐式契约盲区。⓪ 改契约：本 change 为 ADDED Requirement，无旧 Scenario 需处置；现有 tagging-domain 旧测试（GORM default tag / package structure）不受影响，无需「继承与调整」表。

## 白盒附加（简单档，仅年份提取函数）

分支表：无年份→nil｜单年份→该年｜多年份→min｜全角→不匹配（记录）。边界值：1999/2099（正则 `20\d{2}` 不匹配 1999，匹配 2099——2099 与创建年差 ≥1 命中，行为符合"早于创建"语义不存在，作为已知边界记录）。
