# Redesign Reading Pane — 右侧文章主体克制阅读版式

对应 proposal：`redesign-reading-pane`。改动范围仅阅读页右侧文章主体（预览模式），
中间栏列表（`reading-list-panel`）与 iframe 模式不重排。

## User Journey

**入口**：阅读页（`/`，FeedLayoutShell 三栏）中选中一篇文章 → 右侧文章主体区。
主任务：**沉浸阅读正文**——扫一眼来源/时间/标题，顺着排版读完全文。
次任务：查看 AI 摘要 / 标签；关注抓取与总结的处理进度（异常时介入）；
手动触发抓取全文 / 生成总结 / 打标签；收藏、全屏、跳原文。

用户当前痛点（来自对话确认）：
1. 附属组件（状态横幅、摘要卡、简介空块）抢视觉，正文被压下去；
2. 工具栏左侧 feed 名用原色染字（紫色胶囊）刺眼；
3. 正文通栏铺开无阅读重心；主体背景纯色简陋。

## Information Architecture

改动后右侧文章主体区从上到下（预览模式）：

```
┌─ 工具栏（article-header，保持现有高度语言）─────────────────┐
│ [feed 图标 灰色feed名] [状态图标(4态)] 标题(次要灰)  … │ 导航/视图/收藏/全屏/原文 │
├─ 阅读列（reader 语义：max 840px 居中，随面板宽自适应）────────┤
│ 元信息行：日期 · 作者 · 已读（行内小字）                        │
│ 文章大标题（1.6~2.1rem，与列同宽，不再通栏）                   │
│ 标签行（ArticleTagList + 手动打标虚线按钮，仅打标入口）         │
│ 导语段（description 有实质内容时，浅色无边框；无内容不渲染）      │
│ AI 整理稿（有摘要时：小节标题 + 标签 + markdown，无卡片框）      │
│ ── 细分隔线 ──                                                │
│ 正文（markdown-article，同列宽；去外框卡）                     │
│   图片/表格/代码块可 breakout 略宽于正文列（≤ 列宽+160px）       │
└──────────────────────────────────────────────────────────┘
```

移除的独立区块：处理状态横幅（整卡）、内容源切换卡（逻辑保留，入口收进工具栏）、
独立简介卡（降级为导语段）。
信息层级原则：**正文 > 标题/元信息 > 摘要/导语 > 状态 > 手动操作**，
视觉权重自上而下递减，状态与操作不再位于正文之前。

## Interaction Contract

- **主操作（阅读）**：滚动读文；阅读进度条、back-to-top 行为不变。
- **状态图标（新增）**：工具栏上一枚处理状态图标，四态——排队中（琥珀时钟）、
  进行中（info 色旋转）、失败（红 ⚠）、完成（淡灰 ✓，与 reading-list-panel
  四态语义一致）。点击图标开 tooltip 式浮层：抓取/总结/标签三行状态 +
  detailLines（抓取/总结时间、尝试次数）+ 错误文案（失败时）。点击外部或再点关闭。
- **⋯ 菜单（新增）**：工具栏「更多操作」按钮，下拉包含「手动抓取全文」
  「生成 AI 总结」「手动打标签」（按 feed 能力开关显隐；busy 时禁用态），
  以及「内容源切换：原始内容 / Firecrawl 全文」（仅双源可用时出现）。
  菜单项执行反馈沿用现有 loading/error 语义；错误信息在菜单按钮旁以
  行内红色提示呈现（不再占正文上方横幅）。
- **feed 徽章（降色）**：feed 图标保留原色，文字改 `--color-text-secondary`
  灰色（不再用 feed.color 染字）。
- **危险操作**：无（本改动不引入不可逆操作）。
- **键盘/焦点**：⋯ 菜单与状态浮层 Esc 可关；菜单项可 Tab 遍历。

## State Matrix

| 状态 | 呈现 |
| --- | --- |
| loading（抓取/总结进行中） | 状态图标旋转 + tooltip「正在抓取全文…/正在生成总结…」；正文照常可读 |
| error（抓取或总结失败） | 状态图标红色 ⚠ + tooltip 内完整错误文案（超长滚动）；⋯ 菜单内重试入口高亮可点 |
| empty（无摘要） | AI 整理稿区块整体不渲染（不留空卡） |
| empty（无 description / 纯图 / 与正文重复） | 导语段不渲染（guard 收紧后） |
| empty（无正文） | 保留现有「前往原文阅读」按钮居中态 |
| success | 状态图标淡灰 ✓；tooltip 显示完成时间；界面常态静默 |
| busy（手动操作进行中） | ⋯ 菜单项禁用 + 旋转图标；同一时刻仅一个手动操作 |

错误恢复路径：失败 → tooltip 看原因 → ⋯ 菜单重试 → busy → 成功转 ✓ / 仍失败保持 ⚠。

## Layout Contract

- **布局模式**：右侧主体区在 FeedLayoutShell 的 `split` 三栏中属于详情栏；
  本 change 不改三栏骨架。文章主体内部对齐 **`reader` 语义**：
  正文/标题/元信息列 **max-width 840px 居中**（面板窄于 840px 时取面板可用宽）。**修订记录**：2026-09-17 用户超宽屏实测反馈左右留白过多，从 760px 上调至 840px（约 50 汉字/行舒适上限），breakout 余量同步 160→200px——参数级微调，不改布局模式与交互，不触发重审。同日追加：标题加入 breakout（宽度 = 列宽 + breakout 余量），用户反馈标题受限在列内显拘谨。
- **背景（已定案）**：暖米色纵向微渐变（奶油→米白三段），**不加噪点纹理**
  （2026-09 用户对比试看后否决噪点方案：阅读面旁可见颗粒显脏；
  纸感由米白暖色 + 补线标题 + 红 kicker 细线承担，不依赖字面纹理）。
- **排版语言**：标题用衬线字体（Noto Serif SC / 宋体栈，1.7–2.25rem）；
  正文无衬线 1.02rem/行高 2.0；标题上方加红色 kicker 小标（字距 0.22em）
  + 28px 红细线；AI 整理稿与正文间用 34px 红色短粗线转场——
  编辑/杂志签名元素，与 editorial 主题同源。
- **Breakout 元素**（标题/图片/表格/代码块——标题 2026-09-17 用户反馈后加入 breakout）：最宽 = 列宽 + 160px 且 ≤ 面板可用宽度，
  居中；仍放不下时表格内横向滚动。
- **溢出策略**：正文列内表格 `overflow-x: auto`；代码块横向滚动；图片自适应缩放。
- **视口**：桌面 1440×900 与 1920×1080 两档必验（major 契约）；窄屏沿用现有
  768px 断点行为，不新增移动端适配承诺。
- 不新增弹窗；状态浮层与 ⋯ 菜单为小浮层（锚定工具栏，非 AppDialog 场景）。

## Component Reuse

- 复用：`AppButton`（前往原文阅读）、`ArticleTagList`、`FeedIcon`、
  `@iconify/vue Icon`、主题 token（`--color-*` 全套语义变量）；
  状态四态语义与 `reading-list-panel` 的 `useArticleProcessingStatus` 保持同一映射。
- 复用既有浮层形态：状态 tooltip 与 ⋯ 下拉为轻量锚定浮层（参考
  `RowStatusPopover` 的覆盖式定位思路，不改变行/栏高度）。
- **新组件**：`ArticleStatusMenu.vue`（工具栏状态图标 + 详情浮层 + ⋯ 操作菜单，
  一个组件承担两处小浮层，避免 ArticleContentPreviewPanel 再膨胀）。
- **删除**：ArticleContentPreviewPanel 内的处理状态横幅区块与手动按钮行。

## Prototype

静态可丢弃原型：`ui-prototype/index.html`（独立 HTML，内联 CSS，
不连 API、不改产品代码；颜色/间距引用 editorial 主题方向的近似 token 值）。
原型展示：① 工具栏新形态（灰 feed 名 + 状态图标 + ⋯ 菜单，SVG 图标非 emoji，
浮层默认收起点击弹出）；② 阅读列 840px 居中、去卡片化的
kicker/标题/导语/摘要/正文分区；③ 宋体标题、红 kicker、引用块轻左边线、
表格 breakout、暖米色微渐变背景（无噪点）。

## Acceptance

- opencli 主交互链路断言：选中文章 → 正文渲染；状态图标点击开浮层 →
  显示三行状态；⋯ 菜单打开 → 手动操作项按 feed 能力显隐；Esc 关浮层。
- 视觉检查证据（1440×900 + 1920×1080 两档）：正文列 ≤760px 居中、
  无通栏长行；顶部无状态横幅；无卡片叠卡片；宽屏不再拉长视为阻断。
- 组件测试：description guard 新边界用例（纯图/近空文本/与正文重复）；
  ⋯ 菜单显隐逻辑用例。
- 与批准原型的差异说明记录在 tasks.md 验证节；改变信息架构或布局模式的
  修订需重置 approval 后重审。
