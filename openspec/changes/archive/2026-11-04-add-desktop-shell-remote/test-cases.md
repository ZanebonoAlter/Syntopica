## 2. 变体走查（五组）

- **输入**：空串（回退默认）；纯空白（trim 后回退默认）；无 scheme（`10.11.12.55:5100` → 明确报错或补 `http://`，实现须二选一并测试）；畸形 URL（`http://`、`::::`）；超长地址（>2KB）；带尾斜杠（归一化，避免 `//api`）；带路径（`http://h:5100/app` → 保留路径导航）；IPv6 字面量（`http://[::1]:5100/`）——逐项在 `config.rs` 单元测试中给答案。
- **前置**：配置文件不存在（用默认，不报错）；配置文件 JSON 损坏（用默认 + 保留原文件不再覆写）；配置目录不可写（改地址时提示失败但不崩溃）；默认地址可达但返回 500（进失败页而非白屏）——均有答案。
- **时间窗口**：不适用（无时间窗口语义），划除。
- **幂等**：连点「重试」（并发导航，最后一次生效，不产生多窗口/多 WebView）；重复点「修改地址」相同值（幂等写回）；重复启动（单实例）——均有答案。
- **可用性（UI 必检前三）**：误输入反馈（非法地址给出可见错误，而非静默）；空态（不适用，划除）；错误态（失败页）；加载态（首帧底色 + SPA 首屏模板）；超长错误文案（截断到可读长度，不撑破布局）；重复提交（重试连点，见幂等）。

## 4. 白盒附加（complex 分支表）

**地址解析优先级**（`config.rs`）：

| 条件 | 期望 |
| --- | --- |
| 有 `--server-url` | 用它，忽略其余 |
| 无启动参数、有 `SYNTOPICA_SERVER_URL` | 用环境变量 |
| 两者皆无、配置文件有值 | 用配置值 |
| 三者皆无 | 用默认 `http://127.0.0.1:5100/` |
| 配置文件损坏 | 用默认，且不覆写原文件 |
| 值为空/纯空白 | 视为未提供，继续下一级 |

**失败判定**（`nav.rs`）：

| 条件 | 期望 |
| --- | --- |
| 连接拒绝（ECONNREFUSED） | 失败页，原因「服务端未启动或地址不可达」 |
| 超时（> 设定值） | 失败页，原因「连接超时」 |
| 非 2xx 状态 | 失败页，原因「服务端返回 <code>」 |
| 2xx 但非 HTML（如 JSON 错误页） | 仍导航（交给页面渲染），不拦截 |

**配置读写**：

| 条件 | 期望 |
| --- | --- |
| 目录不存在 | 创建后写入 |
| 目录只读 | 返回可见错误，不崩溃 |
| 并发写（两次快速改地址） | 以最后一次为准，文件不出现半截 JSON（先写临时文件再重命名） |
