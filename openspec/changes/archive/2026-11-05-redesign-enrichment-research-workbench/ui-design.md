## User Journey

- 入口：现有版块 `enrichment` tab 展示名为「研究」，不新增顶层频道，旧 tab key 与已有链接继续可达。
- 主任务：扫描建议线索 → 选择一条 → 看问题/依据或读已有报告 → 明确决定是否研究；生成后直接阅读。
- 次任务：忽略/恢复线索、切换报告版本、看真实研究进展、核对原值/公式、查看相关话题背景、读取全部旧研究。
- 背景管理旅程：话题总览 `BoardThreadBrowser` 选中一条可验证话题 → 新闻背景 → 选择周期 → 阅读/编辑；补生成或重新汇总须明确确认。
- 用户已认可主从骨架、正文方向和结构化呈现；又确认研究中不可忽略、旧报告/辩论/问答全保留只读。2026-10-15 展示补充原型后，用户明确选择「批准 UI，继续规划」；本 marker 据此 approved，但本轮仍不得实现。

## Information Architecture

```text
版块 / 研究
├─ 标题、周期、发现研究线索、当前任务入口
├─ split 索引
│  ├─ 全部 / 未研究 / 可阅读 / 已忽略
│  ├─ 紧凑标题 + 来源明确的运行/报告状态
│  └─ 加载更多、历史研究（只读）
└─ 详情
   ├─ 未研究：问题、为什么值得查、新闻依据、相关话题
   ├─ 进行中：真实阶段、进展和失败/结束原因
   └─ 报告：当前判断 → 证据 → 解释 → 后续观察
      ├─ 同候选报告版本、重新研究（次级）
      └─ 原值/公式/完整账本（次级）
```

- 不在工作台继续挂聚焦分析、金融模块或独立新闻背景折叠区。
- 每个候选占一条索引，不把同一报告再在列表底部重复排列；多版报告归在该候选下。历史旧 kind 有独立只读入口，不混入 signal_report 列表。
- 「未研究」筛派生 pending；研究中/成文中不是永久数据库状态，当前任务有独立可达入口，不因筛选或周期变化失联。
- 忽略是候选处理标记，不是报告评审或对结论的赞成/反对；新报告不出现采纳、驳回、judge 徽标。
- 新闻记忆与研究判断分开。研究中打开话题背景为只读预览；管理入口转到相应话题上下文。未知关联显示未关联/缺口，不按相似标题强行绑定。

## Interaction Contract

### 入口、主次动作与实际状态

| 元素 | 可用性 / 确认 | 反馈与边界 |
| --- | --- | --- |
| 周期、筛选、索引选择、版本、加载更多 | 运行中仍可浏览 | 只 GET；不发现、不研究，不把其他 scope 的晚响应写入当前视图 |
| 发现研究线索 | 增强开启且同 board 无任务；显式点击 | 只保存候选；空结果不清历史；不串发研究 |
| 开始研究 | 未忽略、候选可用、增强开启、同 board 无任务 | 一条一任务；冻结材料/cutoff 不变，不预选结论 |
| 重新研究 | 已有报告、未忽略、增强开启且无冲突 | AppDialog sm 确认预算与原快照边界；成功追加版本。用户正在读旧版时不强切 |
| 忽略线索 | 非运行/成文中；请求在途禁重复 | PUT 成功后隐藏；失败回滚/保留现场。报告不删、其他批次不屏蔽 |
| 恢复线索 | 已忽略且请求非在途 | 原候选和报告不变；回正常索引，不触发研究 |
| 已忽略候选的新研究动作 | 禁用并提示先恢复 | 既有报告仍可读；默认 research 的已有报告幂等读取不产生新任务 |
| 当前任务 | 当前 board 有任务时持续可达 | 返回任务所属周期/候选或看进展，不重复启动；切板块不取消原任务 |
| 相关话题 | 依据归属可验证时可点 | 预览有明确 topic 标识；失效/跨板块关联提示缺口，不打开错误话题 |
| 话题新闻背景 | 不依赖增强循环B开关或工作台的旧 selectedTopicId | 话题/粒度/周期独立；GET失败不伪装无记忆 |
| 编辑背景 / 保存 | 话题上下文可用；保存中禁重复 | 只 PUT 指定周期新闻记忆；离开未保存内容需明确放弃或保留草稿，不沉淀研究判断 |
| 补生成 / 重新汇总背景 | 选定话题与周期，显示已有内容覆盖提示后再确认 | 显式 POST；不给浏览/切周期绑定生成，模型故障显示失败而非新空记忆 |
| 历史研究 | 读取不受新研究开关影响 | 只读列表/详情及 QA/辩论/旧review；无触发、追问、沉淀、采纳按钮 |

### 浏览与任务分离

- 浏览上下文键：board + granularity + period + candidate + result；记住索引滚动与各报告阅读位置。局部视图状态可进 URL/sessionStorage，忽略等业务状态必须走 API。
- 新一次筛选若不含当前项，选择第一个可用项或明确空态；后台运行身份独立保存，不被筛选清空。当前周期任务可通过标题区返回。
- 客户端请求带 scope/epoch；旧请求迟到静默丢弃，不弹旧 board 错误、不覆盖新数据、不启动新轮询。切 tab/卸载可停客户端轮询，服务端 job不取消；重进从现有状态API恢复。
- 所有索引均分页，计数若只知当前页必须标「已加载 N 条」，不得由已加载页冒充周期总数，也不把隐藏候选误称为无报告。
- 图表、原值、版本切换只读；未知载荷不执行模型 HTML、不发 AI 修复。新旧数据可能缺字段，缺失写明，不填0或伪造来源。

## State Matrix

| 区域 / 状态 | loading | empty | error / 恢复 | success / 运行态 |
| --- | --- | --- | --- | --- |
| 索引 | 保留宿主与已有上下文，显示加载中 | 本周期/筛选无候选，区分已忽略 | 可重试GET，不把失败当无信号 | 来源字段展示，分页不丢已加载项 |
| 详情 | 独立加载，不清后台job | 提示选择线索 | 保留索引，允许重试/选别条 | 问题、进展或报告；长文独立滚动 |
| 忽略/恢复 | 动作禁重复 | 无标记即正常候选 | 失败还原，原报告仍在 | 刷新/重启保留；运行中按钮禁用+409兜底 |
| 发现/研究 | 阶段和所属候选可见 | 合法无达标结果 | 区分发现、研究、成文、保存失败 | 不研究其他候选；进展终态可回看 |
| 任务恢复 | 查询现有状态 | 无任务不制造running | 重启404停轮询，取持久记录与终态进展 | 不自动续跑、不把预算耗尽当取消 |
| 旧/新报告 | 展示版本加载 | 无成功报告展示问题而非假正文 | 不支持版本/损坏载荷明确报错 | schema2兼容，schema3受控块；无评审链 |
| 证据 | 按需展开 | 缺失/未提供单位、时间显式标注 | 引用失效可定位缺口 | 短格式+原值；公式由程序，分源时效 |
| 话题背景 | scope独立加载 | 该周期未生成；只有显式按钮生成 | 失败提示+重试，不自动补生成 | 周/月/年、编辑、显式补周期；旧all接口兼容 |
| 旧历史 | 列表和选中详情分开加载 | 无该类旧结果，不展示假占位报告 | 单旧载荷错误不吞全列表 | 含归档话题的可验证归属记录，全部子产物只读 |
| 增强开关关闭 | 不拦GET | 有旧数据照常显示 | 新动作禁用并说明，不引导重配模型 | 阅读、背景、历史可用；原开关可显式开启 |
| 长内容/窄屏 | 不撑宽整页 | 不适用 | 超长标题原文可读，不硬裁证据 | 列表省略+完整名称，详情自然换行，弹层能滚动 |

## Layout Contract

- 外层沿用现有版块壳；工作台用 `AppPageShell mode="split"`，各栏 `min-width:0`、独立滚动，不用居中960px容器包住整个工作台。**宽屏（≥768px）双栏定高内滚（2026-10-16 用户反馈后落地）**：工作台占视口剩余高（`calc(100dvh - 190px)`，190px≈顶栏+tab行+研究标题区），左索引/右详情各自 `overflow-y:auto`，页面不再被长列表整体拉长；窄屏保持页面滚不变。详情正文铺满主栏余宽（`workbench-candidate` 无 max-width 帽）。
- 桌面主从栏：索引通常280～352px；768～1099px可降至244px，详情余宽且最小0、不产生整页横向滚动。≥1700px索引352px；正文在详情内 `AppPageShell mode="reader"`，最大760px；列表不是 reader。
- 窄屏断点统一767.98px：默认索引，选中进入单栏详情，返回恢复索引位置与选择；跨断点不清候选/周期，不影响≥768px布局。
- AppDialog：原值核查 `md`=560；背景预览 `md`=560，话题背景管理 `lg`=760；旧历史 `xl`=1040；重研/放弃草稿确认 `sm`=420。上限92vw、垂直内容可滚动、焦点与Escape行为符合既有基础组件。
- 图表保持紧凑（典型绘图区约120～180px，不随reader宽等比膨胀占满半屏），文字HTML层或受控刻度渲染；图表内部尺寸不是另造 page shell。真实日期距离，显式缺失不连线，无法确认连续性时可降离散点。
- 目标视口：1440×900、1920×1080、375×667、390×844；两主题editorial/dark。当前原型展示dark基线，正式editorial验收不可豁免。

## Prototype

- 入口：`ui-prototype/index.html`；附`prototype-extra.js`及`states.html`状态目录，无真实API和外部资源。
- 基线复制自已认可的research原型。新增可点击忽略/恢复、研究中禁用、当前任务、重研确认、版本位置、话题背景管理与全部旧历史。
- `?demo=loading|empty|error|running|disabled|long|bad-report|history|background` 为原型检查入口，不进入正式产品路由。
- 话题总览按钮在原型中直接模拟“已选中话题后打开背景”，不表示重做话题总览；版本选择只演示位置，正式实现用result_id取独立快照。原型忽略仅内存，正式要求服务端持久。
- 示例数据来自人工fixture/用户截图，未重新核验；不把此图当真实成文结果，也不据此宣称模型契约已验证。
- 本文从pending开始，已于2026-10-15经用户明确确认更新approved（见human-feedback.md FB-7）。审批仅固定后续实现的合同，不覆盖本轮planning-only边界；重大布局/主流程变动须重新审批。
