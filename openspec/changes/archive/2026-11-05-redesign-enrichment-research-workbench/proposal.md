## Why

现有数据增强页面把候选、报告及多代遗留能力纵向堆叠，研究切换困难，新闻背景又依赖另一折叠区的话题选择；报告把原始精度、研究过程与论证混在一起，难以阅读。先交付边界清楚的研究工作台及可靠的呈现组件，不借此次改版重造持续研究引擎。

## What Changes

- 将版块 tab 的展示名改为「研究」，保留既有 tab key / 链接兼容；采用「线索索引 + 问题/进展/报告详情」主从布局，窄屏为列表、详情、原位返回。
- 浏览、筛选、翻页、切换周期和查看历史都不触发模型；保留发现与逐条研究的显式边界、任务互斥和冻结材料语义。
- 增加独立的候选处理标记：持久化忽略 / 恢复，默认索引隐藏已忽略候选，不改候选快照或删除报告。用户已确认研究中不可忽略；忽略仅针对当前候选，不屏蔽话题或未来批次。
- 拆出可复用的数值引用、证据表、图表与报告章节组件。阅读短格式与原值核查分层，显示来源、原生单位、真实期间与缺口；不将源精度字符串直接当正文或图上标签。
- 最小扩展新报告的受控成文协议：保留四种论证角色，允许段落、证据表、图表引用按语义编排；模型提交文案与证据 ID，不提交任意 HTML/CSS/图表配置，也不抄写数值。旧 schema=2 原文兼容，新产物单独版本化，不批量改写或重新研究旧报告。
- 新闻背景回到话题上下文：在话题总览选中话题后可直接打开，并保留周期回看、编辑及显式补生成；工作台只提供相关话题的上下文查看入口。关联只从可验证依据解析，没有关联不硬绑泳道。
- **BREAKING（产品入口，不是 API 删除）**：移除新工作台中的金融辩论、旧聚焦分析及其追问/沉淀生成入口，不再将它们作为主线工具。
- 增加只读历史入口，覆盖用户确认保留的旧版板块报告、聚焦分析、已有金融辩论、问答及可关联旧评审信息；使用原有载荷兼容视图，不要求符合新报告格式。旧后端触发 API 保留兼容，本 change 不发起或续跑这些任务。

### Non-goals

不为每条泳道新建研究项目；不新增用户自由提问、自动持续研究、假设评分、自动观点合并、跨周期同题归并、评审/采纳链、通用搜索/正文抓取工具或新数据源；不更换研究模型/研究预算；不改话题生命周期、关键事件筛选及旧数据归属。后续持续研究能力另开 change。

## Capabilities

### New Capabilities

无。新行为归入既有能力，避免另一套工作台规范。

### Modified Capabilities

- `board-signal-reports`: 主从工作台、候选独立忽略标记、确定性话题依据关联、受控报告布局/格式化、按证据显示时效，以及新旧载荷和快照兼容。
- `data-enrichment`: 「研究」入口与话题新闻背景的分工，背景的独立话题上下文，旧报告问答等只读历史可达性及新旧入口边界。
- `board-level-analysis`: 取消聚焦生成下钻，保留旧产物只读渲染与归属校验；更新旧工作台信息架构约定，防止与新布局冲突。

## Impact

- 前端：`front/app/features/tags/components/BoardEnrichmentPanel.vue`、`SignalCandidateList.vue`、`SignalReportView.vue`、`TagsPage.vue`、`BoardThreadBrowser.vue`；相关 composables、API/normalizer、`signalReport.ts`、现有 legacy reader 组件。新增呈现与背景组件以既有 AppPageShell/AppDialog 和双主题 token 实现，不引入新图表依赖。
- 后端：`backend-go/internal/dataenrichment/{handler,service,repository}/` 和 `routes.go`；候选 disposition 持久化、分页查询、候选详情与依据关联、只读历史聚合、成文校验及序列化。研究工具循环、现有资料快照与计算引擎保持不变。
- API：新增候选处理标记/详情、可验证相关话题、旧历史查询等只读或轻量写入契约；候选列表增加显式 visibility 筛选，省略该参数保留旧客户端语义。均需 owner 校验；忽略与研究启动的竞争在同版块门禁内处理。
- 存储：只加独立候选处理标记表及必要索引，不修改候选内容；报告新版本只追加，原附录/公式/数值不变。迁移测试必须在一次性 PG 中运行。
- 文档：更新 data-enrichment/topic-graph 流程，相关 API、schema、前端呈现标准与导航地图；明确取代仍要求聚焦折叠区的旧 UI 文案，保留事实/判断隔离等业务红线。
- 并发：`add-topic-key-event-markers` 正在进行；话题总览宿主必须先盘点交点，不覆盖它的事件筛选、布局或导航实现。

### 部署后影响与需要的操作

- 用户会看到「研究」主从工作台、可忽略线索与更清楚的报告；旧生成入口退役但历史结果可查。
- 不需手工清理、配置新模型、重新生成历史数据；仅需正常发布带增量迁移的后端和重新构建部署前端。
- 旧 schema=2 只做格式与布局适配，不擅自重写正文或提升结论；未知/损坏载荷显示明确兼容错误，不能伪装空报告或触发 AI 修复。
- 当前仅规划。本次制品生成不执行迁移、不访问业务数据、不部署、不修改产品代码。
