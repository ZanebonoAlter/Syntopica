## User Journey

**入口**：侧边栏"发现订阅源"下方新增常驻入口"文章搜索"（mdi:magnify 图标）→ `/search` 独立页面。与发现订阅源同组（浏览/发现类导航区），位于分隔线之前。

**主任务**：找回文章——用户记得文章讲什么，输入关键词（中文为主，自然输入习惯为**连续短语**如「特斯拉电池自燃」，非空格分词），从全站 38K 篇文章（含 94.6% 已归档）中定位那篇，**点开文章预览弹窗快速浏览**，深入阅读再全文跳转。

**次任务**：
- 发现相关——不搜具体词，搜概念（"电动车电池安全"），语义路径命中相关标签下的近期文章；
- 无结果补救——关键词无命中时，一键开启 LLM 扩展搜索，用同义词扩展词重查无标签老文章。

## Information Architecture

```
/search 页面（单一层级，无子路由）
├── 页面标题「文章搜索」
├── 搜索工具条
│   ├── 搜索输入框（大，自适应宽）+ 搜索按钮
│   └── 过滤行：含归档切换（默认开）｜LLM 扩展开关（默认关）｜结果摘要（N条·语义命中M标签·耗时）
├── 通知条（仅语义降级时出现，常隐）
├── 结果列表
│   ├── 结果卡片 ×N（复用 ArticleCardView 形态 + 命中原因 chip + 已归档角标）
│   ├── 扩展结果分隔条「以下 X 条来自扩展搜索」+ 扩展词回显（仅扩展开启时）
│   └── 加载更多（分页）
└── （无结果/初始时）空态引导区
```

导航关系：**结果卡片点击 → 文章预览弹窗（复用 `ArticlePreviewModal`，非路由跳页）**——搜索场景要求快速过滤结果，弹窗内文本预览保留命中词高亮，「阅读全文」才进入阅读页；关闭弹窗返回列表原位（查询与滚动位置保留，session 内）。

## Interaction Contract

**主操作**：
- 输入查询（回车 / 搜索按钮）→ 执行搜索（重复提交防护：进行中禁用按钮+输入不变不重查）
- **查询预处理（四层字面管线，实验定标）**：
  - L0 空格显式拆分（用户可控通道）；
  - L1 标签概念词典切词：3~8 字概念标签（8,293 词）做正向最大匹配，切出词逐词 AND LIKE——实验数据：词重组/概念/混合词三类场景召回从 0~2% 拉至 100%，必选；
  - L2 整串子串 LIKE（精确）；
  - L3 trigram 模糊兜底：**阈值 0.10**（目标 p50=0.143 / 非目标 p99=0，区分度完美，低阈值安全；召回 26% 独占词典外+不连续场景）；
  - 语义路径整句 embedding 不受分词影响；LLM 开启时拆词+同义扩展补跑 L1/L2。
- 排序补偿：单词 AND 放宽召回（mix 场景均 16 篇）→ 多词命中加权 > 单词命中，交 RRF 消化
- 查询变更后过滤器（含归档切换）→ 立即重查

**次操作**：
- LLM 扩展开关开启 → 当前查询立即带扩展重查；后续查询默认携带
- 点结果卡片 → **打开文章预览弹窗（复用 `ArticlePreviewModal`：AppDialog 90vw/85vh，文本预览与内嵌网页双模式，命中词高亮）**，不跳页
- 弹窗内「阅读全文」→ 阅读页；Esc/遮罩关闭 → 返回列表原位
- 卡片收藏按钮 → 现有收藏行为（stop propagation）
- 加载更多 → 追加下一页（offset 分页）

**反馈方式**：
- 命中原因 chip（每卡）：🔍关键词命中（info 色）｜🏷语义命中标签+分数（success 色）｜✨扩展词命中（warning 色）
- 已归档角标：灰描边小标签，卡片整体降饱和
- 结果摘要行：结果数、语义命中标签数、耗时
- 扩展结果分隔条：明确区分主结果与扩展结果

**危险操作**：无（本页无删除/不可逆动作）。

## State Matrix

| 状态 | 触发 | 表现 | 恢复路径 |
|---|---|---|---|
| 初始空态 | 进入页面未搜索 | 大图标+引导文案（"输入关键词，搜全站文章"） | 输入即离场 |
| Loading（首查） | 提交查询 | 骨架屏×3 行（封面+双行 shimmer） | 自动离场，P50<1s |
| Loading（追加） | 加载更多 | 按钮内 spinner + 禁用 | 自动离场 |
| Empty（无结果） | ①+② 均零命中 | 空态+「开启 LLM 扩展搜索再试」引导按钮 | 点按钮→开启扩展自动重查 |
| Success | 有结果 | 结果列表+命中 chip+归档角标 | — |
| Error（API 失败） | /api/search 非 2xx | 错误条+重试按钮，保留输入 | 重试 |
| 语义降级 | embedding 不可用 | 静默跳过语义路径，黄色通知条"已降级为纯关键词结果"，不阻塞不报错 | 自动恢复（下次查询重试） |
| 扩展失败 | LLM 不可用且已开启 | 主结果正常显示，扩展区不出现，toast 提示一次 | 下次查询重试 |

## Layout Contract

- **layout mode**：`AppPageShell mode="contained"`（最大宽 1120px 居中）——普通列表浏览筛选页，符合布局契约默认；结果卡片行自适应内容列宽，无横向溢出（命中 chip 多时折行）。
- **目标视口**：1440×900、1920×1080 双档验收（contained 居中不超限）；窄屏 375×667 / 390×844 降级单栏（过滤行折行堆叠，卡片封面缩至 40px）。
- **dialog**：本页无 dialog。
- **自由宽度**：无。

## Prototype

`ui-prototype/index.html`——单文件静态原型（editorial + dark 双主题 token 纯复刻，右上角按钮切换；不连 API、不改产品代码）。直接浏览器打开即可。包含：

- SCENE B 主形态：侧边栏入口位置（高亮+NEW 标）+ 搜索工具条 + 四种结果卡片（关键词命中/语义命中+分数/已归档角标/扩展结果）+ 扩展分隔条 + 分页
- SCENE A/C/D/E 状态卡：初始空态、Loading 骨架、无结果引导扩展、语义降级通知条

**实现精度授权（用户 2026-10-13 批准时明确）**：实现不需 1:1 复刻原型，按实际组件场景实现，参考原型骨架与功能交互即可；样式细节以现有基础组件与主题 token 为准。
