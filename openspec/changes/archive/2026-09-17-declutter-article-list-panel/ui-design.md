# UI Design: declutter-article-list-panel

## 1. User Journey

主链路不变：进入阅读页 → 中间栏**扫标题/来源/时间**挑文章 → 需要时 📅 筛日期、ⓘ 查订阅源健康 → 点击行在右侧阅读。变的是中间栏的角色定位：从「仪表盘 + 卡片摞」回归**扫描-选择面板**——常态零 chip 干扰（处理成功/排队不显示任何状态），异常与可展开信息统一为「小图标 → 点开浮层看详情」一套交互。选中行、已读行、hover 反馈保留既有语义。

## 2. Information Architecture

中间栏自上而下两层（对比改前五段）：

```
┌────────────────────────────┐
│ 智源社区 376    [7天内×] 📅 ⓘ │ ← 头部行（唯一 chrome 层）
├─ (下拉浮层：日期面板 / 订阅 popover) ─┤
│ ─────────────────────────  │
│ 标题最多两行 …            ☆ │ ← 行列表（无限重复）
│ 来源 · 相对时间 · 作者   ⚠ 🏷 │    meta 行右端：条件角标
│ ─────────────────────────  │
```

- **头部行**：标题 + 计数常驻；筛选激活时插入条件 chip（如「7天内 ×」）；📅 日期筛选按钮、ⓘ 订阅源状态按钮（仅单 feed 视图显示 ⓘ）。
- **行**：标题（≤2 行，14px semibold）→ meta 行（来源 · 相对时间 · [作者]），meta 行右端**单一状态图标**（四态：排队=琥珀 ⏳ / 处理中=⟳ / 失败=红 ⚠ / 全部完成=淡灰 ✓）+ ☆ 收藏常驻右上角。
- **展开浮层**：状态图标点开「处理详情」浮层——抓取/总结/标签三行状态 + 失败错误文案，就地覆盖、不改变行高、不挤动列表流。

## 3. Interaction Contract

| 交互 | 触发 | 反馈 | 关闭 |
| --- | --- | --- | --- |
| 选中文章 | 点击行 | 选中态高亮（accent-subtle 底 + 左侧 2px accent 竖条），右侧加载正文 | 点其他行切换 |
| 收藏 | 点 ☆ | 图标实心/描边切换（既有语义） | — |
| 日期筛选 | 点 📅 | 头部下方弹出日期面板（快速选项 + 起止日期 + 清除/应用） | 再点 📅 / 点面板外 / 应用后自动收起 |
| 清除筛选 | 点条件 chip × | 恢复全部日期，chip 消失 | — |
| 订阅源状态 | 点/悬停 ⓘ | popover 浮层：刷新/总结/抓取 三行只读 + 「在设置中调整」文案指引 | 点面板外 / 再点 ⓘ |
| 查看处理详情 | 点行尾状态图标（任意态可点，含完成态） | 就地浮层：抓取/总结/标签 三行状态；失败时浮层附错误文案（可滚动）；标签只显示 待打标签/已标记 N（列表数据不含标签名，引导去语义版块/阅读区查看） | 点浮层外 / 再点图标 |
| 键盘 | 维持现状 | 本次不新增键盘导航，不改变现有可达性基线 | — |

浮层通用规则：绝对定位覆盖下方内容（视觉上「就地展开」，技术上不参与虚拟列表行高）；同一行同时只开一个浮层；打开另一个行的浮层时自动关闭前者。

## 4. State Matrix

| 维度 | 状态 | 呈现 |
| --- | --- | --- |
| 行-阅读态 | 默认 / hover / 选中 / 已读 | 默认无底色；hover 全行微底色；选中 accent-subtle 底+左竖条；已读整行 opacity-60（既有） |
| 行-状态图标 | 排队（抓取或总结 pending/incomplete） | meta 行右端琥珀 ⏳（--color-secondary），可点开详情 |
| | 进行中（抓取中/总结中） | ⟳ 小转圈（info 色，animate-spin），可点开详情 |
| | 失败（抓取/总结） | 红 ⚠（--color-error），可点开详情 |
| | 全部完成 | 淡灰 ✓（几乎隐形、保留浮层入口） |
| 处理详情浮层 | 开 | 抓取/总结/标签 三行状态；失败行附错误文案；标签只显示 待打标签/已标记 N |
| 头部 | 日期面板 关/开 | 开时面板下拉，📅 按钮呈激活色 |
| | 筛选 未激活/激活 | 激活时头部插入条件 chip「<范围> ×」 |
| | ⓘ 隐藏/显示 | 仅单 feed 视图显示（全部文章/分类/收藏夹无 feed 状态可看） |
| 列表整体 | 加载中 / 空态 / 加载更多 / 已到底 | 沿用现状文案与图标，仅按新 surface 换肤 |

## 5. Layout Contract

- **页面级**：维持既有三栏 split（侧栏 + 列表面板 + 阅读区），本 change 不改 page shell 布局模式、不改各栏宽度（面板仍 20rem）。
- **中间栏内部（本 change 主战场）**：
  - Surface 统一：整栏单一底色 `--color-bg-base`（#faf7f2），头部行与列表行同底，仅以 1px `--color-border-subtle` 分隔线与留白分层——消除「白条 + 咖啡底」拼贴的根因。
  - 行高基准：行式布局后行高收敛固定基准（**v5 修订：~100px**——封面槽 68px + 上下留白 14px×2 + 标题两行/meta；虚拟列表 `itemHeight` 与新基准对齐，消除滚动错位）。
  - **封面槽（v5 新增）**：每行左侧 68×68 圆角槽，数据源 `articles.image_url`（object-fit: cover）；`image_url` 为空 → feed 图标居中的浅底占位（`--color-bg-sunken` + `--color-text-muted` 图标），**行高不变**、视觉节奏统一；封面加载失败同样降级为占位，不换行高。
  - 展开浮层：absolute 定位、宽 = 行宽 - 16px、max-height 160px 内滚动、z-index 高于相邻行；底色 MUST 用实心 `--color-bg-base` + `--color-border-medium` 边 + `--shadow-medium` 投影——**禁用半透明 `--color-bg-hover` 作浮层底**（原型验证会透出下层文字）。
  - 分隔线：行间 1px border-subtle；列表首行与头部之间不画线（留白分层）。
- **目标视口**：1440×900 与 1920×1080 双视口验收；窄屏/移动端不在本次范围（现有响应式行为不变）。

## 6. Component Reuse

- `FeedIcon`：单 feed 视图头部可在标题旁沿用（可选）；行内维持不显示 feed 图标（compact 语义不变）。
- `AppButton`：日期面板「清除筛选/应用筛选」沿用 secondary/primary sm 档。
- `@iconify/vue` `Icon`：全部使用本地子集**已有**图标名（mdi:calendar-filter / mdi:information-slab-circle / mdi:tag-outline / mdi:tag / mdi:alert-circle / mdi:loading / mdi:star / mdi:star-outline / mdi:chevron-* 均为现有在用名，**无新增**，不触发 `pnpm generate:icons`）。
- 颜色/阴影/圆角：全走 `main.css` 语义 token（bg-base / bg-elevated / accent / accent-subtle / error / border-subtle / border-medium / text-* / shadow-*），**禁止硬编码色值**，双主题（light/dark）自动适配；原型仅为 light 态视觉基准。
- 浮层：若实现抽象成小组件，放 `features/articles/components/`（如 `RowStatusPopover.vue`），不引第三方浮层库（项目无此依赖）。

## 8. Acceptance

### 验收记录（2026-09-18 实测）

- **机械断言**：✅ 组件测试 15/15 绿（四态图标 / 浮层三行内容与失败错误文案 / 浮层互斥与点外关闭 / 单 feed 隐藏来源名 / 事件）；`pnpm lint` 0 error、`nuxi typecheck` 0 error、`pnpm test:unit` 除存量环境性失败（stash 后复跑同样红，非本 change 引入）外全绿、`pnpm build` 成功、后端 `go build ./...` 成功（零后端影响）。
- **真应用主链路（浏览器实测留痕）**：点行选中（accent-subtle+左竖条+右侧加载正文）、状态图标浮层开合与互斥、📅 面板开合→应用 7 天→条件 chip「7天内 ×」出现→点击 chip 清除、单 feed 视图 ⓘ popover（刷新正常/总结开启/抓取开启+设置指引）、行高全部 80px。
- **双视口**：1440×900 与 1920×1080 均无横向溢出、无拼贴色块、浮层定位正确。

### 与已批准原型的差异说明（均属实现细节修正，不涉及信息架构/布局模式，不重置审批）

1. **meta 行改为「相对时间打头 · 身份位按视图切换」**：原型样张即时间在前的形态；实现将「单 feed 视图显作者 / 多 feed 视图显来源」统一为时间打头 + 单行省略号截断（原型部分样张曾以来源打头），已同步回写 spec Scenario。
2. **行高固定 80px**：实测自然行高两档（64.9/83.8）会破坏虚拟列表对齐，按 design D1 收敛为固定行高（标题 clamp + meta nowrap 保证内容不溢出）。
3. **头部浮层挂载点**：日期面板/订阅 popover 实现为 header 子元素（absolute 于 header）——初版作为 header 兄弟节点渲染时包含块解析错误（浮层落到面板底部），已修正；spec 无需变更（契约只约束呈现形态）。
4. **浮层防裁剪**：列表最后一行的浮层会被虚拟列表 overflow 容器裁剪，实现加了「底边空间不足时向上翻」逻辑（design D2 风险预案落地）。
5. **移除行内「已读」文字标记**：已读态已有整行 opacity 弱化，文字标记冗余且挤占 meta 单行空间（原型基准即无此标记）。
