版块体检全链路

日报成功后自动运行的纯读体检：双口径统计 → LLM 评分（方法学锚）→ 快照落库 → 通知闸门 → 面板与扩充召回消费。形状承载类型：圆角胶囊是端点，矩形是步骤，菱形是判定。

insufficient 不是病（2026-10-08 口径修正）

口径②已改贴合度分布，覆盖全量挂载 tags

  • 旧「纯净样本（只挂单个 aux 的 tag）」口径覆盖仅 1.4%~6.8% 且样本池不增长，2026-10-08 真库实测后废弃，改为构成标签 × 全部挂载 tags 的贴合度分布
  • insufficient = 证据缺失 ≠ 标签失效 ≠ 内容匮乏（2026-10-03 修复：评分 prompt 增方法学锚）
  • 不硬凑分布是红线（semantic-board 红线 22）

评分 <60 的真实病征

insufficient 数量不是扣分项

  • 幽灵匹配占比高（ghost / matched，如 25%）
  • 有样本标签 cosine 普遍 < 0.5
  • matched_tags 相对构成规模萎缩；弱路径（hit_rate / max_sim / weighted）主导且 composite ≈ 0

降级与通知语义

统计永不因 LLM 丢失

  • LLM 坏 JSON / 超时 → score=NULL 不重试，统计照常落快照
  • score ≥ 60 永不通知；冷却 3 天内（严格 <）不重复；NULL 轮永不通知
  • 体检纯读：不写匹配表、不落任何扩充建议
